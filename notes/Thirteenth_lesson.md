# NumPy — урок 13. Транслирование массивов (broadcasting)

В этом уроке разобрал broadcasting и функцию `np.ix_()`.

## 1. Что такое broadcasting

Broadcasting — механизм NumPy, который позволяет выполнять операции над массивами разных форм, если их размерности совместимы.

Например, можно прибавить одно число ко всем элементам массива:

```python
import numpy as np

a = np.array([1, 2, 3])

print(a + 10)
# [11 12 13]
```

Также можно выполнять операции с двумерным массивом и одномерным:

```python
a = np.array([[1, 2, 3],
              [4, 5, 6]])

b = np.array([10, 20, 30])

print(a + b)

# [[11 22 33]
#  [14 25 36]]
```

Массив `b` применяется к каждой строке массива `a`.

## 2. Правила broadcasting

NumPy сравнивает размерности массивов справа налево.

Размерности совместимы, если:
- Они равны.
- Одна из них равна 1.
- Отсутствующие размерности считаются равными 1.

Пример:

```python
a = np.ones((3, 1))
b = np.ones((1, 4))

c = a + b

print(c.shape)  # (3, 4)
```

Здесь массивы как бы растягиваются до формы `(3, 4)`.

При этом NumPy обычно не создаёт реальные копии растянутых массивов.

### Пример несовместимых размерностей

```python
a = np.ones((3, 2))
b = np.ones((3,))

# a + b  # ValueError
```

Формы `(3, 2)` и `(3,)` несовместимы, потому что при сравнении справа получаем `2` и `3`.

## 3. Broadcasting со столбцом и строкой

```python
a = np.array([[1],
              [2],
              [3]])

b = np.array([10, 20, 30])

print(a + b)

# [[11 21 31]
#  [12 22 32]
#  [13 23 33]]
```

Формы массивов:

- `a.shape` — `(3, 1)`
- `b.shape` — `(3,)`, при сравнении размерностей рассматривается как `(1, 3)`
- Результат — `(3, 3)`

Каждый элемент столбца `a` складывается со всеми элементами строки `b`.

## 4. Функция np.ix_()

`np.ix_()` помогает подготовить одномерные массивы к операциям с использованием broadcasting.

Функция добавляет размерности так, чтобы можно было работать со всеми комбинациями элементов.

```python
a = np.array([1, 2])
b = np.array([3, 4, 5])

x, y = np.ix_(a, b)

print(x)
# [[1]
#  [2]]

print(y)
# [[3 4 5]]

print(x.shape)  # (2, 1)
print(y.shape)  # (1, 3)
```

Теперь массивы можно перемножить поэлементно:

```python
print(x * y)

# [[ 3  4  5]
#  [ 6  8 10]]
```

Итоговая форма — `(2, 3)`.

Важно: `np.ix_()` не меняет сами значения, а добавляет оси для совместной работы массивов.

## 5. np.ix_() с тремя массивами

```python
a = np.array([1, 2, 3])
b = np.array([4, 5])
c = np.array([7, 8, 9, 10])

an, bn, cn = np.ix_(a, b, c)

print(an.shape)  # (3, 1, 1)
print(bn.shape)  # (1, 2, 1)
print(cn.shape)  # (1, 1, 4)

result = an * bn + cn

print(result.shape)  # (3, 2, 4)
```

Здесь для каждой комбинации элементов `a`, `b` и `c` вычисляется выражение:

`a[i] * b[j] + c[k]`

## 6. Что запомнить

- Broadcasting позволяет выполнять операции над массивами разных форм.
- Размерности сравниваются справа налево.
- Размерности совместимы, если они равны или одна из них равна 1.
- Если размерностей не хватает, они мысленно добавляются слева.
- `(3, 1) + (1, 4)` даёт результат формы `(3, 4)`.
- `(3, 2) + (3,)` вызывает ошибку.
- `np.ix_()` добавляет оси для работы со всеми комбинациями элементов.
- `np.ix_()` особенно удобна при работе с несколькими одномерными массивами.

Главное — понимать правила совместимости размерностей, а не пытаться запоминать формы наизусть.
