# NumPy: свойства массивов, view и copy

## Свойства массива

a = np.array([1, 2, 3, 4, 5])

a.dtype      # тип элементов
a.size       # количество элементов
a.itemsize   # размер одного элемента в байтах
a.ndim       # число измерений
a.shape      # форма массива

Пример:

a = np.array([0.1, 0.2, 0.3])

print(a.dtype)      # float64
print(a.size)       # 3
print(a.itemsize)   # 8
print(a.ndim)       # 1
print(a.shape)      # (3,)

Многомерный массив:

b = np.ones((3, 4, 5))

print(b.ndim)       # 3
print(b.shape)      # (3, 4, 5)

## Представление (view)

view() создает новый массив, который ссылается на те же данные.

Изменение данных в одном массиве отражается в другом.

a = np.array([1, 2, 3, 4, 5])
b = a.view()

a[0] = 100
print(b)            # [100 2 3 4 5]

## Копия (copy)

copy() создает независимый массив с собственными данными.

Изменение данных в одном массиве не влияет на другой.

a = np.array([1, 2, 3, 4, 5])
b = a.copy()

a[0] = 100
print(b)            # [1 2 3 4 5]

## Сравнение view и copy

| Свойство              | view() | copy() |
|-----------------------|--------|--------|
| Общие данные          | Да     | Нет    |
| Изменения отражаются  | Да     | Нет    |
| Независимость         | Нет    | Да     |

## reshape и view

reshape() часто возвращает view, а не копию.

b = np.ones((3, 4, 5))
c = b.reshape(3, 2, 10)

b[0, 0] = 10
print(c)            # изменения видны в c

## Что запомнить

dtype — тип элементов
size — количество элементов
itemsize — размер одного элемента в байтах
ndim — число измерений
shape — форма массива
view() — представление, общие данные
copy() — копия, независимые данные
