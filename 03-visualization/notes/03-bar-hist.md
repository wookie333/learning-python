# Урок 3. Столбчатые диаграммы и гистограммы

## 1. bar() и barh()

bar() — вертикальная столбчатая диаграмма.
barh() — горизонтальная столбчатая диаграмма.

Используются для сравнения категорий.

bars = ax.bar(categories, sales)
ax.barh(regions, revenue)

Основные параметры:
- color — цвет столбцов
- width — ширина столбцов
- edgecolor — цвет границы
- label — подпись для легенды

## 2. Сортировка данных

zip() объединяет элементы двух списков попарно.
sorted() сортирует полученные пары.

Пример:

units = [180, 340, 95]
items = ["Ноутбуки", "Телефоны", "Наушники"]

pairs = sorted(zip(units, items))

Результат:
[(95, "Наушники"), (180, "Ноутбуки"), (340, "Телефоны")]

Можно разделить отсортированные пары:

units_sorted = [p[0] for p in pairs]
items_sorted = [p[1] for p in pairs]

## 3. Группированные столбцы

Позволяют сравнивать несколько значений для одной категории.

x = np.arange(len(months))
width = 0.35

ax.bar(x - width / 2, plan, width, label="План")
ax.bar(x + width / 2, fact, width, label="Факт")

Сдвиги влево и вправо нужны, чтобы столбцы стояли рядом.

## 4. Накопленные столбцы

Используются для отображения суммы нескольких показателей.

ax.bar(months, online)
ax.bar(months, retail, bottom=online)

bottom указывает, с какой высоты начинается второй столбец.

Пример: онлайн = 40, розница = 30.
Общая высота столбца = 70.

## 5. Гистограмма hist()

hist() показывает распределение числовых данных по интервалам.

ax.hist(prices, bins=20)

bins — количество интервалов или список их границ.

Пример:

prices = [3, 4, 7, 8, 8, 9, 12, 15, 22, 40]

counts, edges, patches = ax.hist(
    prices, bins=[0, 5, 10, 20, 50]
)

counts = [2, 4, 2, 2] — количество значений в интервалах.
edges = [0, 5, 10, 20, 50] — границы интервалов.
patches — графические объекты столбцов.

Интервалы имеют вид [a, b), последний — [a, b].
Например, число 5 входит в [5, 10), но не в [0, 5).

## 6. Генерация случайных данных

np.random.seed(11) — фиксирует последовательность случайных чисел.

checks = np.random.gamma(2.0, 800, 300)

Гамма-распределение:
- 2.0 — параметр формы (shape)
- 800 — параметр масштаба (scale)
- 300 — количество значений

Теоретическое среднее: shape * scale = 1600.

## 7. Подписи и дополнительные линии

ax.bar_label(bars) — значения над столбцами.
fmt="%d" — отображение целых чисел.

ax.axvline(x, color="red") — вертикальная линия в точке x.
ax.axhline(y, color="red") — горизонтальная линия в точке y.

Пример:

ax.axvline(checks.mean(), color="red", linestyle="--")

Линия показывает средний чек.

## Итог

bar/barh — сравнение категорий.
hist — распределение числовых данных.
bins — интервалы гистограммы.
bar_label — подписи столбцов.
axvline — вертикальная линия.

Для ML особенно важны hist(), bins и анализ распределений.
