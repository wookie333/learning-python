# Matplotlib — Урок 6. Оформление графиков для ML

## 1. Легенда: label и legend()

Позволяет различать линии на одном графике.

    ax.plot(epochs, train_loss, label="Train Loss")
    ax.plot(epochs, val_loss, label="Validation Loss")
    ax.legend()

- label — название линии.
- legend() — отображает легенду.
- loc="upper right" — расположение легенды.

Применение: сравнение train loss и validation loss.

## 2. Аннотации: annotate()

Позволяет подписать важную точку стрелкой.

    best = np.argmin(val_loss)

    ax.annotate(
        "Best loss",
        xy=(epochs[best], val_loss[best]),
        xytext=(epochs[best] - 2, val_loss[best] + 0.2),
        arrowprops=dict(arrowstyle="->", color="black")
    )

- argmin() — индекс минимального значения.
- xy — координаты точки, куда указывает стрелка.
- xytext — координаты текста.
- arrowprops — оформление стрелки.

Пример: если best = 5, то epochs[best] = 6, поскольку индексация начинается с нуля.

Важно: xytext можно выбирать самостоятельно, чтобы текст не перекрывал данные.

Если добавить textcoords="offset points", значения xytext станут смещениями относительно xy в типографских пунктах.

Применение: выделение лучшей эпохи обучения.

## 3. Сетка: grid()

    ax.grid(True, axis="y", alpha=0.3)

- True — включить сетку.
- axis="y" — горизонтальные линии сетки.
- alpha — непрозрачность от 0 до 1.

Применение: удобное чтение значений loss и метрик.

## 4. Пороговые линии

    ax.axhline(y=0.5, color="red", linestyle="--")
    ax.axvline(x=6, color="gray", linestyle="--")

- axhline() — горизонтальная линия на уровне Y.
- axvline() — вертикальная линия на уровне X.

Применение: порог метрики, лучшая эпоха, момент остановки обучения.

## 5. Заливка: fill_between()

    ax.fill_between(epochs, train_loss, val_loss, alpha=0.2)

Общий вид:

    ax.fill_between(x, y1, y2, color="blue", alpha=0.2)

- x — значения горизонтальной оси.
- y1 — первая граница.
- y2 — вторая граница.
- color — цвет заливки.
- alpha — прозрачность.

Закрашивает область между двумя кривыми.

Применение: интервалы неопределённости прогнозов, сравнение кривых обучения.

Важно: для настоящих доверительных или предсказательных интервалов границы должны быть рассчитаны статистически, а не выбраны произвольно.

## 6. Сохранение графика: savefig()

    fig.savefig("training_loss.png", dpi=200, bbox_inches="tight")

- Имя файла — куда сохранить график.
- dpi — разрешение изображения.
- bbox_inches="tight" — сокращает лишние поля.

Сохранять желательно до plt.show().

Применение: графики для GitHub README, ML-проектов и отчётов.

## Необязательное на текущем этапе

- plt.style.use() — готовые стили оформления.
- rcParams — глобальные настройки Matplotlib.
- bbox_to_anchor — точное положение легенды.
- Палитры цветов — улучшение читаемости графиков.

## Главное

Для ML важно уметь:
1. Сравнивать train loss и validation loss.
2. Находить и отмечать лучшую эпоху.
3. Показывать пороги и интервалы.
4. Подписывать графики и сохранять их.
