# Урок 9. Тепловые карты и корреляция

## 1. Тепловая карта (Heatmap)

Тепловая карта представляет числовую матрицу
в виде цветных ячеек.

    fig, ax = plt.subplots()
    im = ax.imshow(data, cmap="viridis")
    fig.colorbar(im, ax=ax)
    plt.show()

- fig — фигура (полотно).
- ax — область построения графика.
- im — объект созданного изображения.
- imshow() — визуализация матрицы.
- colorbar() — цветовая шкала.

## 2. Основные параметры

- cmap — цветовая палитра.
- vmin — нижняя граница цветовой шкалы.
- vmax — верхняя граница цветовой шкалы.
- origin="upper" — первая строка матрицы сверху.
- origin="lower" — первая строка матрицы снизу.
- shrink=0.85 — уменьшение длины цветовой шкалы до 85%.
- ticks — подписанные значения на цветовой шкале.

Популярные палитры:

- viridis — отображение числовых величин.
- Blues — последовательная синяя палитра.
- coolwarm — отображение положительных и отрицательных
  значений, например коэффициентов корреляции.

## 3. Подписи осей

    ax.set_xticks(range(len(labels)), labels)
    ax.set_yticks(range(len(labels)), labels)
    ax.set_title("Heatmap")

Названия строк и столбцов задаются через ticks,
а не через legend().

## 4. Аннотации внутри ячеек

    for i in range(data.shape[0]):
        for j in range(data.shape[1]):
            value = data[i, j]

            ax.text(j, i, f"{value:.2f}",
                    ha="center", va="center",
                    color="white" if abs(value) > 0.7
                    else "black")

- shape[0] — количество строк.
- shape[1] — количество столбцов.
- i — индекс строки.
- j — индекс столбца.
- ha — горизонтальное выравнивание.
- va — вертикальное выравнивание.
- :.2f — два знака после десятичной точки.

Важно:

    data[i, j]       # строка, столбец
    ax.text(j, i)    # координаты X, Y

## 5. Пропущенные значения

    masked = np.ma.masked_invalid(data)
    cmap = plt.get_cmap("Blues").copy()
    cmap.set_bad("#EEEEEE")

    ax.imshow(masked, cmap=cmap)

NaN и бесконечные значения маскируются.
Замаскированные ячейки отображаются серым цветом.

Пропуск не является нулевым значением.

## 6. Ковариация

Ковариация характеризует совместное изменение
двух числовых величин.

    Cov(X, Y) = sum((xi - mean_x) * (yi - mean_y)) / n

Пример:

    X = [20, 40, 60]
    Y = [5, 10, 15]

    mean_x = 40
    mean_y = 10

    Cov(X, Y) = ((-20)*(-5) + 0*0 + 20*5) / 3
    Cov(X, Y) = 200 / 3 = 66.67

Положительная ковариация — величины имеют тенденцию
изменяться в одном направлении.

Отрицательная — в противоположных направлениях.

Ковариация зависит от масштаба и единиц измерения.

Свойство:

    Cov(X, X) = D(X)

## 7. Дисперсия и стандартное отклонение

    D(X) = sum((xi - mean_x)**2) / n
    sigma = sqrt(D(X))

В NumPy:

    np.mean(X)  # среднее
    np.var(X)   # дисперсия
    np.std(X)   # стандартное отклонение

По умолчанию np.var() и np.std() используют деление
на n. Для деления на n-1 используется ddof=1.

## 8. Коэффициент корреляции Пирсона

Корреляция Пирсона характеризует силу и направление
линейной связи между двумя величинами.

    r = Cov(X, Y) / (sigma_X * sigma_Y)

Диапазон значений: от -1 до 1.

- r = 1 — идеальная положительная линейная связь.
- r = -1 — идеальная отрицательная линейная связь.
- r = 0 — отсутствие линейной корреляции.

Знак показывает направление связи.
Модуль показывает силу линейной связи.

Например, r = -0.95 означает более сильную линейную
связь, чем r = 0.6.

Продолжение предыдущего примера:

    D(X) = 800 / 3
    D(Y) = 50 / 3

    sigma_X = 16.33 (приблизительно)
    sigma_Y = 4.08 (приблизительно)

    Cov(X, Y) = 66.67 (приблизительно)

    r = 1 (без промежуточного округления)

Корреляция не определена, если стандартное отклонение
хотя бы одной величины равно нулю.

## 9. Матрица корреляций в NumPy

    corr = np.corrcoef(data)

По умолчанию каждая строка data — отдельная переменная,
а столбцы — наблюдения.

Если переменные расположены в столбцах:

    corr = np.corrcoef(data, rowvar=False)

Или можно транспонировать массив:

    corr = np.corrcoef(data.T)

Для двух переменных:

    corr = np.corrcoef(X, Y)
    print(corr[0, 1])

Для n переменных получается матрица n x n.

Свойства матрицы:

- симметрична;
- на главной диагонали стоят единицы для переменных
  с ненулевой дисперсией;
- каждый элемент показывает корреляцию пары переменных.

Округление для вывода:

    print(np.round(corr, 2))

## 10. Тепловая карта корреляций

    fig, ax = plt.subplots()

    im = ax.imshow(corr, cmap="coolwarm",
                   vmin=-1, vmax=1)

    ax.set_xticks(range(len(labels)), labels)
    ax.set_yticks(range(len(labels)), labels)

    fig.colorbar(im, ax=ax)
    plt.show()

Фиксированные границы -1 и 1 позволяют одинаково
интерпретировать цвета разных матриц корреляций.

## 11. Аналог в Seaborn

    import seaborn as sns

    sns.heatmap(corr,
                annot=True,
                fmt=".2f",
                cmap="coolwarm",
                vmin=-1, vmax=1,
                xticklabels=labels,
                yticklabels=labels)

    plt.show()

annot=True — автоматические подписи внутри ячеек.
fmt=".2f" — два знака после десятичной точки.

Seaborn позволяет обойтись без ручного двойного цикла.

## 12. Применение в ML и Data Science

Матрицы корреляций используются для:

- разведочного анализа данных (EDA);
- изучения взаимосвязей между признаками;
- анализа связи признаков с целевой переменной;
- выявления сильно коррелирующих признаков.

Важные ограничения:

- Корреляция не доказывает причинно-следственную связь.
- Нулевая корреляция не исключает нелинейную зависимость.
- Нельзя автоматически удалять признаки только
  на основании коэффициента корреляции.
- Выбросы могут существенно влиять на корреляцию.

Пример: продажи мороженого и кондиционеров могут
коррелировать из-за общей причины — жаркой погоды.
