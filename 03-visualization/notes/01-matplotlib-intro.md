## 1. Что такое Matplotlib

Matplotlib — библиотека Python для визуализации данных.

Основной импорт:

```python
import matplotlib.pyplot as plt
```

## 2. Первый график

```python
days = ['Пн', 'Вт', 'Ср', 'Чт', 'Пт', 'Сб', 'Вс']
revenue = [42, 38, 45, 51, 66, 89, 74]

plt.plot(days, revenue)
plt.show()
```

- `plt.plot(x, y)` — строит линейный график.
- `plt.show()` — отображает фигуру.
- Значения X и Y должны иметь одинаковую длину.

## 3. Figure и Axes

Два основных объекта Matplotlib:

- **Figure (`fig`)** — весь холст, на котором располагаются графики.
- **Axes (`ax`)** — отдельная область построения графика с осями и подписями.

```python
fig, ax = plt.subplots()
```

`plt.subplots()` создаёт Figure и один или несколько Axes.

Важно: `Axes` — область графика, а `Axis` — отдельная координатная ось.

## 4. Два стиля работы

### Pyplot

```python
plt.plot([1, 2, 3], [10, 15, 20])
plt.title("Продажи")
plt.xlabel("Месяц")
plt.ylabel("Выручка")
plt.show()
```

### Объектный стиль

```python
fig, ax = plt.subplots()

ax.plot([1, 2, 3], [10, 15, 20])
ax.set_title("Продажи")
ax.set_xlabel("Месяц")
ax.set_ylabel("Выручка")

plt.show()
```

Объектный стиль удобнее, когда нужно управлять несколькими графиками.
Для дальнейшей практики предпочитаем его.

## 5. Размер фигуры

```python
fig, ax = plt.subplots(figsize=(10, 3))
```

`figsize=(ширина, высота)` задаёт размеры Figure в дюймах.

## 6. Несколько графиков

```python
fig, axes = plt.subplots(1, 2, figsize=(10, 4))

axes[0].plot([1, 2, 3], [10, 20, 15])
axes[0].set_title("Выручка")

axes[1].plot([1, 2, 3], [5, 8, 12])
axes[1].set_title("Количество заказов")

plt.show()
```

- `fig` — общая фигура.
- `axes[0]` — первый график.
- `axes[1]` — второй график.

## 7. Сохранение графика

```python
fig.savefig("plot.png", dpi=150)
plt.show()
```

- `savefig()` сохраняет фигуру в файл.
- `dpi` определяет разрешение растрового изображения.
- Обычно сохраняем фигуру до `plt.show()`.

Это полезно для отчётов, README и ML-проектов.

## 8. Основные типы графиков

| Метод | Назначение |
|---|---|
| `plot()` | Изменения и тенденции, например по времени |
| `bar()` | Сравнение категорий |
| `scatter()` | Связь двух числовых признаков |
| `hist()` | Распределение числовых значений |

Подробно изучим эти типы в следующих уроках.

## Главное

Figure — общий холст.
Axes — отдельная область графика.

Объектный стиль Matplotlib позволяет настраивать каждый график
отдельно и хорошо сочетается с Seaborn.
