# Seaborn — визуализация данных для ML

Seaborn — библиотека статистической визуализации,
построенная поверх Matplotlib.

## Основные параметры

- data — исходный DataFrame.
- x, y — столбцы для построения графика.
- hue — разделение наблюдений по цвету.
- ax — область построения графика.

## 1. Scatterplot

    sns.scatterplot(data=df, x="budget", y="revenue",
                    hue="genre", alpha=0.7)

Показывает взаимосвязь между двумя признаками.

## 2. Countplot

    sns.countplot(data=df, x="genre")

Подсчитывает количество объектов в каждой категории.
Полезен для обнаружения дисбаланса классов.

## 3. Histplot

    sns.histplot(data=df, x="rating", bins=20, kde=True)

Показывает распределение признака.
kde=True добавляет кривую оценки плотности.

## 4. KDEplot

    sns.kdeplot(data=df, x="rating", hue="genre", fill=True)

- fill — заполнение области под кривой.
- bw_adjust — степень сглаживания.

Используется для сравнения распределений разных групп.

## 5. Boxplot

    sns.boxplot(data=df, x="genre", y="rating")

Показывает медиану, квартили, разброс и выбросы.
Выбросы нельзя удалять автоматически без анализа.

## 6. Heatmap

    corr = df.select_dtypes(include="number").corr()

    sns.heatmap(data=corr, annot=True, cmap="coolwarm",
                vmin=-1, vmax=1, fmt=".2f")

- annot — отображение чисел внутри ячеек.
- vmin, vmax — границы цветовой шкалы.
- fmt — формат отображения чисел.
- cmap — цветовая палитра.

Корреляция Пирсона:
- +1 — идеальная положительная линейная связь.
- -1 — идеальная отрицательная линейная связь.
- 0 — отсутствие линейной связи.

Нулевая корреляция не означает независимость.
Корреляция не означает причинно-следственную связь.

Сильная корреляция между признаками может
указывать на избыточность информации.

## 7. Pairplot

    sns.pairplot(data=df, vars=["rating", "budget", "revenue"],
                 hue="genre", corner=True)

- vars — анализируемые столбцы.
- corner — удаление дублирующихся графиков.
- Диагональ — распределения признаков.
- Остальные ячейки — попарные зависимости.

## 8. Regplot

    sns.regplot(data=df, x="budget", y="revenue", ci=None)

Строит scatterplot и линию регрессии.

- ci=None — отключение доверительного интервала.
- scatter_kws — параметры отображения точек.

## 9. Barplot

    sns.barplot(data=df, x="genre", y="rating")

По умолчанию рассчитывает среднее значение
числового признака для каждой категории.

Countplot — количество объектов.
Barplot — агрегированное значение.

## 10. Lineplot

    sns.lineplot(data=df, x="year", y="revenue",
                 hue="genre", errorbar=None)

По умолчанию рассчитывает среднее Y для каждого X.
errorbar=None отключает отображение интервала.

## 11. Несколько графиков на одном полотне

    fig, axes = plt.subplots(2, 3, figsize=(15, 10))

    sns.histplot(data=df, x="rating", ax=axes[0, 0])

    fig.tight_layout()
    plt.show()

## EDA — Exploratory Data Analysis

Разведочный анализ данных:

1. Изучение структуры датасета.
2. Проверка пропусков и дубликатов.
3. Описательная статистика.
4. Анализ распределений и выбросов.
5. Анализ корреляций и взаимосвязей.
6. Формулирование выводов.

EDA помогает понять данные перед обучением модели.
