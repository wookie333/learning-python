# Урок 10. Финальный проект — Movie Data Analysis

## Цель проекта

Разведочный анализ синтетического датасета из 200 фильмов
с использованием NumPy, Pandas и Matplotlib.

## Генерация данных

- np.random.default_rng(42) — воспроизводимый генератор.
- rng.choice() — случайный выбор элементов.
- rng.integers() — случайные целые числа.
- rng.normal() — нормальное распределение.
- rng.uniform() — равномерное распределение.
- clip() — ограничение диапазона значений.
- np.round() — округление.
