# Matplotlib — урок 5. Pie и Subplots

## 1. Круговые диаграммы — pie()

pie() показывает доли категорий от общего значения.

Пример:

    labels = ["Chrome", "Safari", "Edge"]
    share = [63, 19, 18]

    fig, ax = plt.subplots()
    ax.pie(share, labels=labels)
    plt.show()

Основные параметры:

- labels — названия категорий.
- autopct — отображение процентов.
- explode — выдвижение отдельных секторов.
- startangle — начальный угол диаграммы.

Пример:

    ax.pie(
        share,
        labels=labels,
        autopct="%1.1f%%",
        explode=[0.08, 0, 0],
        startangle=90
    )

Форматирование autopct:

- "%1.0f%%" — 25%
- "%1.1f%%" — 25.0%
- "%1.2f%%" — 25.00%

explode=[0.08, 0, 0] выдвигает первый сектор.
startangle=90 задаёт начальный угол 90 градусов.

Важно: pie неудобен при большом количестве категорий.
Для сравнения близких значений лучше использовать bar().

## 2. Кольцевая диаграмма — Donut

Donut — круговая диаграмма с отверстием внутри.

    ax.pie(
        budget,
        labels=labels,
        wedgeprops={"width": 0.42},
        startangle=90
    )

wedgeprops — настройки внешнего вида секторов.
width — толщина кольца.

Текст внутри диаграммы:

    ax.text(0, 0, "Кв. 4", ha="center", fontsize=13)

- (0, 0) — координаты текста.
- ha="center" — выравнивание по горизонтали.
- fontsize — размер шрифта.

## 3. Figure и Axes

Figure — весь рисунок.
Axes — отдельная область с графиком.

    fig, ax = plt.subplots()

Один Figure содержит один Axes.

Несколько графиков:

    fig, (ax1, ax2) = plt.subplots(
        1, 2, figsize=(12, 5)
    )

- 1 — количество строк.
- 2 — количество столбцов.
- figsize — размер рисунка в дюймах.
- ax1 и ax2 — отдельные графики.

## 4. Сетки графиков — subplots()

Создание сетки 2x2:

    fig, axs = plt.subplots(2, 2, figsize=(12, 8))

Обращение к графикам:

    axs[0, 0]  # верхний левый
    axs[0, 1]  # верхний правый
    axs[1, 0]  # нижний левый
    axs[1, 1]  # нижний правый

Первый индекс — строка, второй — столбец.
Индексация начинается с нуля.

Для сетки 2x2 axs — двумерный массив объектов Axes.

## 5. Заголовки и оформление

    ax.set_title("Название графика")
    ax.set_xlabel("Ось X")
    ax.set_ylabel("Ось Y")

    fig.suptitle("Общий заголовок", fontsize=14)
    fig.tight_layout()

set_title() — заголовок отдельного графика.
suptitle() — заголовок всего рисунка.
fontsize — размер шрифта.

tight_layout() автоматически настраивает отступы,
чтобы подписи и заголовки не перекрывались.

## 6. Общие оси — sharex и sharey

    fig, (ax1, ax2) = plt.subplots(
        1, 2, sharey=True
    )

sharey=True — общая шкала Y.
sharex=True — общая шкала X.

Это удобно при сравнении нескольких графиков.

## 7. Легенда — label и legend()

    ax.scatter(actual, predicted, label="Predicted")
    ax.plot(actual, actual, label="Ideal")
    ax.legend()

label задаёт название элемента графика.
legend() отображает легенду.

## 8. Применение в Machine Learning

Визуализация предсказаний:

    ax.scatter(actual, predicted)

actual — реальные значения.
predicted — предсказания модели.

Линия идеальных предсказаний:

    ax.plot(actual, actual)

Она соответствует y = x.
Чем ближе точки к линии, тем точнее предсказания.

График обучения модели:

    ax.plot(epochs, loss, marker="o")

epochs — номера эпох обучения.
loss — значение функции потерь.

Снижение training loss означает уменьшение
ошибки на обучающих данных по выбранной функции,
но не гарантирует качество на новых данных.

## 9. Частые ошибки

1. В pie() передавать названия вместо числовых данных.
2. В scatter() передавать только один аргумент.
3. Путать порядок X и Y в plot() и scatter().
4. Путать индексы axs[строка, столбец].
5. Забывать legend() при использовании label.

## Краткий итог

- pie() — круговая диаграмма.
- autopct — проценты на секторах.
- explode — смещение секторов.
- startangle — начальный угол.
- wedgeprops — оформление секторов.
- subplots() — несколько графиков.
- figsize — размер Figure.
- suptitle() — общий заголовок.
- tight_layout() — автоматические отступы.
- sharex/sharey — общие оси.
- label/legend() — легенда.
