# Matplotlib — линейные графики

## 1. Построение линий

```python
fig, ax = plt.subplots(figsize=(10, 5))
ax.plot(x, y)
plt.show()
```

- `fig` — вся фигура.
- `ax` — область построения графика.
- `plot(x, y)` — линейный график.
- `plot(y)` — X автоматически равен индексам элементов.
- Несколько `ax.plot()` на одном `ax` — несколько линий.

## 2. Оформление линий

- `color` — цвет линии.
- `marker="o"` — круглые маркеры.
- `marker="s"` — квадратные маркеры.
- `linestyle="--"` — пунктирная линия.
- `linewidth=2` — толщина линии.
- `alpha=0.5` — прозрачность.
- `label` — название для легенды.

Короткий формат: `"g^-"` — зелёная сплошная линия с треугольниками.

## 3. Подписи и оси

```python
ax.set_title("Заголовок")
ax.set_xlabel("Ось X")
ax.set_ylabel("Ось Y")
ax.legend()

ax.grid(True, axis="y", alpha=0.3)
ax.set_ylim(0, 250)
ax.tick_params(axis="x", labelrotation=30)
```

- `legend()` показывает подписи линий.
- `grid()` включает сетку.
- `set_xlim()` и `set_ylim()` задают видимый диапазон осей.
- `labelrotation` поворачивает подписи делений.

## 4. NumPy и графики

- `np.arange()` — создаёт последовательность значений.
- `np.sin()` — позволяет моделировать плавные колебания.
- `np.random.normal()` — генерирует случайные значения.
- `np.cumsum()` — накопленная сумма.
- `np.convolve()` — свёртка, в примере урока используется для скользящего среднего.

Скользящее среднее сглаживает колебания данных, позволяя лучше увидеть тенденцию.

## 5. Важные замечания

- Массивы X и Y должны иметь одинаковую длину.
- Для отображения названий линий нужен `legend()`.
- Не стоит перегружать один график большим количеством линий.
- Оси желательно подписывать с единицами измерения.
- Цвет, прозрачность и стиль линии помогают выделять главное.
