# Matplotlib — Scatter Plot

## 1. Диаграмма рассеяния

`scatter()` строит диаграмму рассеяния — график, показывающий связь между двумя числовыми переменными.

Каждая точка соответствует одному наблюдению:
- X — значение первого признака;
- Y — значение второго признака.

```python
import matplotlib.pyplot as plt
import numpy as np

area = [30, 40, 50, 60]
price = [4.5, 6.0, 7.2, 9.0]

fig, ax = plt.subplots()

ax.scatter(area, price)
ax.set_title("Зависимость цены от площади")
ax.set_xlabel("Площадь, м²")
ax.set_ylabel("Цена, млн руб.")

plt.show()
```

В Data Science scatter используют для исследования признаков, поиска зависимостей, кластеров и выбросов.

## 2. Основные параметры scatter

```python
ax.scatter(x, y, s=50, alpha=0.5, color="blue")
```

| Параметр | Назначение |
|----------|------------|
| `x`, `y` | Координаты точек |
| `s` | Площадь маркеров в pt² |
| `alpha` | Непрозрачность от 0 до 1 |
| `color` | Общий цвет точек |
| `c` | Цвета точек или значения для их окрашивания |
| `cmap` | Цветовая карта |
| `label` | Название группы для легенды |

### Параметр s

`s` определяет площадь маркеров, а не их радиус.

```python
ax.scatter(x, y, s=20)
ax.scatter(x, y, s=80)
```

Во втором случае площадь маркеров в 4 раза больше, а линейный размер примерно в 2 раза больше.

Можно передать список размеров:

```python
rooms = [1, 2, 3, 4, 5]
sizes = [r ** 2 * 60 for r in rooms]
```

Здесь размер каждого маркера зависит от количества комнат.

### Параметр alpha

`alpha` управляет прозрачностью:

- `alpha=1` — полностью непрозрачные точки;
- `alpha=0.5` — полупрозрачные;
- `alpha=0.2` — слабозаметные точки;
- `alpha=0` — полностью прозрачные.

Прозрачность особенно полезна при большом количестве наблюдений.

## 3. Несколько групп и легенда

На одном scatter можно отобразить несколько групп данных.

```python
area = [30, 40, 50]

fig, ax = plt.subplots()

ax.scatter(area, [6, 8, 10], label="Центр")
ax.scatter(area, [4, 5, 7], label="Окраина")

ax.set_xlabel("Площадь")
ax.set_ylabel("Цена")
ax.legend()

plt.show()
```

`label` задаёт название группы.

`ax.legend()` отображает легенду.

Так можно сравнивать зависимость между признаками у разных категорий объектов.

## 4. Цвет как дополнительный признак

Помимо X и Y, информацию можно передавать цветом.

```python
area = [30, 40, 50, 60]
price = [4, 5, 7, 9]
age = [35, 20, 10, 5]

fig, ax = plt.subplots()

points = ax.scatter(
    area,
    price,
    c=age,
    cmap="viridis",
    s=90
)

fig.colorbar(points, label="Возраст дома, лет")
plt.show()
```

Разбор:

- `c=age` — цвет зависит от возраста дома;
- `cmap="viridis"` — цветовая палитра;
- `s=90` — одинаковая площадь маркеров;
- `points` — объект, возвращаемый `scatter()`;
- `colorbar()` — шкала соответствия цветов значениям.

Таким способом на двумерном графике можно показать третью переменную.

## 5. Аннотации

`annotate()` добавляет подпись к выбранной точке.

```python
ax.annotate(
    "Элитная отделка",
    xy=(66, 12.8),
    xytext=(48, 11.6),
    arrowprops=dict(arrowstyle="->")
)
```

Параметры:

- `xy` — координаты точки, на которую указывает стрелка;
- `xytext` — координаты расположения текста;
- `arrowprops` — параметры стрелки;
- `arrowstyle="->"` — стрелка с наконечником.

Аннотации полезны для выделения выбросов и необычных наблюдений.

## 6. Overplotting

Overplotting — наложение большого количества точек друг на друга.

Когда точки непрозрачные, сложно определить, где наблюдений больше.

```python
np.random.seed(7)

x = np.random.normal(0, 1, 2000)
y = np.random.normal(0, 1, 2000)

fig, ax = plt.subplots()
ax.scatter(x, y, s=12, alpha=0.3)

plt.show()
```

Способы уменьшить проблему:

1. Уменьшить размер точек через `s`.
2. Использовать прозрачность через `alpha`.
3. Для очень больших наборов данных рассмотреть `hexbin()` или двумерные гистограммы.

При наложении полупрозрачных точек области с большим количеством наблюдений выглядят темнее.

## 7. Корреляция Пирсона

Коэффициент корреляции Пирсона показывает направление и силу линейной связи между двумя переменными.

Он находится в диапазоне от -1 до 1.

- `r = 1` — идеальная положительная линейная связь;
- `r = -1` — идеальная отрицательная линейная связь;
- `r ≈ 0` — слабая линейная связь или её отсутствие.

Пример:

```python
x = np.array([1, 2, 3, 4, 5])
y = np.array([2, 4, 5, 4, 5])

r = np.corrcoef(x, y)[0, 1]

print(round(r, 2))
```

`np.corrcoef(x, y)` возвращает матрицу корреляций:

```text
[[1.   r]
 [r    1.]]
```

Разбор индексов:

- `[0, 0]` — корреляция X с самим собой;
- `[0, 1]` — корреляция X с Y;
- `[1, 0]` — корреляция Y с X;
- `[1, 1]` — корреляция Y с самим собой.

`[0, 1]` извлекает нужный коэффициент.

Важно:
- Корреляция не доказывает причинно-следственную связь.
- Нулевая корреляция не означает статистическую независимость.
- Корреляция Пирсона измеряет именно линейную связь.

## 8. Генерация синтетических данных

```python
np.random.seed(3)

height = np.random.normal(172, 9, 300)

weight = (
    (height - 100) * 0.9
    + np.random.normal(0, 7, 300)
)

r = np.corrcoef(height, weight)[0, 1]

fig, ax = plt.subplots()

ax.scatter(height, weight, s=14, alpha=0.4)

ax.set_title(f"Рост и вес: r = {r:.2f}")
ax.set_xlabel("Рост, см")
ax.set_ylabel("Вес, кг")

plt.show()
```

Разбор:

### np.random.seed(3)

Фиксирует состояние генератора случайных чисел для воспроизводимости результата.

### np.random.normal(172, 9, 300)

Генерирует 300 случайных значений из нормального распределения:

- `172` — математическое ожидание;
- `9` — стандартное отклонение;
- `300` — количество значений.

### (height - 100) * 0.9

Искусственная линейная зависимость веса от роста.

Например, при росте 180 см базовый вес по формуле составит 72 кг.

### np.random.normal(0, 7, 300)

Добавляет случайный шум со средним 0 и стандартным отклонением 7.

Благодаря шуму точки не располагаются строго на одной прямой.

### np.corrcoef(height, weight)[0, 1]

Вычисляет линейную корреляцию роста и веса.

### f"Рост и вес: r = {r:.2f}"

Добавляет вычисленный коэффициент корреляции в заголовок и отображает его с двумя знаками после запятой.

Синтетические данные используют для экспериментов, проверки алгоритмов и визуализации зависимостей.

## 9. Применение в Machine Learning

Диаграммы рассеяния полезны при разведочном анализе данных (EDA).

Основные задачи:

1. Исследование связей между числовыми признаками.
2. Поиск выбросов и аномалий.
3. Сравнение разных групп объектов.
4. Анализ распределения наблюдений в пространстве признаков.
5. Визуальная проверка предполагаемых зависимостей.
6. Сравнение предсказаний модели с реальными значениями.

Scatter помогает понять структуру данных ещё до обучения модели.

## 10. Краткая шпаргалка

| Конструкция | Назначение |
|-------------|------------|
| `ax.scatter(x, y)` | Диаграмма рассеяния |
| `s=50` | Площадь маркеров |
| `alpha=0.3` | Прозрачность |
| `c=values` | Цвет по значениям |
| `cmap="viridis"` | Цветовая карта |
| `fig.colorbar(points)` | Шкала цветов |
| `label="Группа"` | Подпись группы |
| `ax.legend()` | Легенда |
| `ax.annotate(...)` | Аннотация точки |
| `np.corrcoef(x, y)[0, 1]` | Корреляция Пирсона |
| `np.random.normal(...)` | Случайные данные из нормального распределения |
| `np.random.seed(...)` | Воспроизводимость генерации |

Главное: scatter показывает взаимосвязи между признаками, но визуальная зависимость сама по себе не доказывает причинность.
