# Числа Фибоначчи

## Теория

Последовательность Фибоначчи:

F(0) = 0
F(1) = 1
F(n) = F(n-1) + F(n-2)

Пример: 0, 1, 1, 2, 3, 5, 8, 13, 21...

Каждое следующее число равно сумме двух предыдущих.

---

## 1. Небольшое число Фибоначчи

### Условие

Дано целое число n (1 <= n <= 40).
Необходимо вычислить n-е число Фибоначчи.

Пример:

Ввод: 3
Вывод: 2

### Решение

[01-fibonacci.py](01-fibonacci.py)

Используем две переменные:
- a — текущее число Фибоначчи;
- b — следующее число Фибоначчи.

На каждой итерации:

    a, b = b, a + b

Python сначала вычисляет правую часть по старым
значениям, затем обновляет обе переменные.

После n итераций переменная a содержит F(n).

### Сложность

- Время: O(n)
- Дополнительная память: O(1)

Обычная рекурсия без мемоизации работает гораздо
медленнее из-за повторных вычислений.

## 2. Последняя цифра большого числа Фибоначчи

### Условие

Дано целое число n (1 <= n <= 10^7).
Найти последнюю цифру F(n).

Пример:

Ввод: 841645
Вывод: 5

### Решение

[02-last-digit.py](02-last-digit.py)

Нам не нужно вычислять огромное число целиком.
Достаточно хранить последние цифры соседних чисел.

    a, b = b, (a + b) % 10

Операция % 10 оставляет последнюю цифру суммы.

Например:

13 + 21 = 34
(3 + 1) % 10 = 4

Последняя цифра суммы зависит только
от последних цифр слагаемых.

### Сложность

- Время: O(n)
- Дополнительная память: O(1)

Количество итераций остаётся прежним,
но мы избегаем арифметики с огромными числами.

## 3. Огромное число Фибоначчи по модулю

### Условие

Даны два целых числа:
- 1 <= n <= 10^18
- 2 <= m <= 10^5

Нужно найти остаток от деления F(n) на m.

Пример:

Ввод: 10 2
Вывод: 1

Поскольку F(10) = 55, получаем 55 % 2 = 1.

### Решение

[03-fibonacci-mod.py](03-fibonacci-mod.py)

При очень большом n обычный цикл слишком медленный.
Используем период Пизано.

Период Пизано — длина повторяющейся последовательности
остатков чисел Фибоначчи по модулю m.

Для m = 3:

0, 1, 1, 2, 0, 2, 2, 1, 0, 1...

Период равен 8: через восемь шагов
снова появляется начальная пара (0, 1).

### Алгоритм

1. Находим длину периода Пизано для m.
2. Сокращаем n с помощью n % period.
3. Вычисляем остаток за оставшиеся итерации.

Пример:

    n = 1002
    m = 3
    period = 8

    n = 1002 % 8 = 2

Вместо 1002 итераций второго цикла делаем 2.

Ответ: F(1002) % 3 = 1.

Важно различать:

    n % period

Сокращает количество необходимых итераций.

    (a + b) % m

Вычисляет следующий остаток числа Фибоначчи.

Первый цикл ищет длину периода,
второй — значение остатка на нужной позиции.

### Сложность

- Время: O(m)
- Дополнительная память: O(1)

Для m >= 2 длина периода Пизано не превышает 6m.

---

## Главное

- Для Фибоначчи достаточно хранить два соседних числа.
- Одновременное присваивание сохраняет старые значения.
- Операция % 10 позволяет находить последнюю цифру.
- Период Пизано позволяет работать с огромным n.
- n % period и (a + b) % m решают разные задачи.
