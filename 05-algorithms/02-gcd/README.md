# Алгоритм Евклида (НОД)

## Теория

НОД(a, b) — наибольшее положительное число,
на которое a и b делятся без остатка.

Примеры:

НОД(18, 12) = 6
НОД(35, 18) = 1

Основное свойство алгоритма Евклида:

    gcd(a, b) = gcd(b, a % b)

Если b = 0, то НОД равен a.

---

## 1. Наибольший общий делитель

### Условие

Даны два целых числа a и b:

1 <= a, b <= 2 * 10^9

Необходимо найти их наибольший общий делитель.

Пример 1:

Ввод: 18 35
Вывод: 1

Пример 2:

Ввод: 14159572 63967072
Вывод: 4

### Решение

[gcd.py](gcd.py)

Используем рекурсивный алгоритм Евклида.

На каждом шаге заменяем пару:

    (a, b) -> (b, a % b)

Пример для gcd(35, 18):

    gcd(35, 18)
    gcd(18, 17)
    gcd(17, 1)
    gcd(1, 0)

Когда b становится равным нулю,
возвращаем a.

Ответ: 1.

### Почему это работает

Пусть d — общий делитель a и b.

Число a можно представить так:

    a = q * b + r

где r = a % b.

Если a и b делятся на d,
то остаток r тоже делится на d.

Обратно: если b и r делятся на d,
то a = q * b + r тоже делится на d.

Следовательно, общие делители пар
(a, b) и (b, a % b) совпадают.

Поэтому их НОД одинаковы.

### Сложность

- Время: O(log(min(a, b)))
- Память: O(log(min(a, b))) из-за рекурсии

Отдельно проверять a >= b не требуется.
Алгоритм работает независимо от порядка чисел.

---

## Главное

- Алгоритм Евклида основан на остатке от деления.
- При каждом рекурсивном вызове задача уменьшается.
- Условие b == 0 останавливает рекурсию.
- НОД сохраняется при замене (a, b) на (b, a % b).
