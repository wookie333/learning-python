# NumPy: математические операции над массивами

NumPy позволяет выполнять математические операции сразу над всеми элементами массива, без цикла `for`.

## 1. Операции со списками и массивами

```python
import numpy as np

lst = [1, 2, 3]
a = np.array([1, 2, 3])

print(lst * 2)  # [1, 2, 3, 1, 2, 3]
print(a * 2)    # [2 4 6]
```

У списка `* 2` повторяет элементы, а у массива NumPy умножает каждый элемент на 2.

## 2. Основные операции

```python
a = np.array([1, 2, 3])

print(-a)    # [-1 -2 -3]
print(a - 3) # [-2 -1  0]
print(a + 2) # [3 4 5]
print(a / 2) # [0.5 1.  1.5]
print(a % 2) # [1 0 1]
print(a ** 2) # [1 4 9]
```

| Операция | Что делает |
|---|---|
| `-a` | Меняет знак элементов |
| `a + 2` | Прибавляет число |
| `a - 2` | Вычитает число |
| `a * 2` | Умножает элементы |
| `a / 2` | Делит элементы |
| `a % 2` | Возвращает остаток от деления |
| `a ** 2` | Возводит элементы в степень |

## 3. Операции между массивами

Если массивы одинаковой формы, операции выполняются между соответствующими элементами.

```python
a = np.array([1, 2, 3])
b = np.array([3, 4, 5])

print(a * b)
# [ 3  8 15]
```

Это обычное поэлементное умножение, а не матричное.

## 4. Операции с массивами разной формы

NumPy может выполнять операции с массивами разной формы, если их размеры совместимы. Это называется broadcasting.

```python
matrix_a = np.array([1, 2, 3])
matrix_b = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print(matrix_a * matrix_b)
# [[ 1  4  9]
#  [ 4 10 18]]
```

Массив `[1, 2, 3]` применяется к каждой строке матрицы.

## 5. Изменение массива на месте

Операторы вроде `+=` позволяют изменить существующий массив:

```python
new_a = np.array([1, 2, 6, 8])

new_a += 5

print(new_a)
# [ 6  7 11 13]
```

`new_a += 5` прибавляет 5 к каждому элементу и сохраняет результат в `new_a`.

## Что запомнить

- Арифметические операции NumPy обычно выполняются поэлементно.
- Число можно прибавить, вычесть или применить к каждому элементу массива.
- `a * b` — поэлементное умножение, не матричное.
- Broadcasting позволяет работать с массивами разной формы, если их размеры совместимы.
- `+=` изменяет значения массива на месте.
