# NumPy — урок 11. Произведение матриц и линейная алгебра

В этом уроке разобрал умножение векторов и матриц, а также основные функции модуля `np.linalg`.

## 1. Поэлементное и матричное умножение

В NumPy оператор `*` умножает элементы массивов, а `@` выполняет матричное произведение.

```python
import numpy as np

a = np.array([[1, 2],
              [3, 4]])

b = np.array([[2, 0],
              [1, 2]])

print(a * b)
# [[2 0]
#  [3 8]]

print(a @ b)
# [[ 4  4]
#  [10  8]]
```

Для матричного умножения можно использовать:

```python
np.dot(a, b)
np.matmul(a, b)
a @ b
```

Для обычного умножения матриц удобнее всего `@`.

Важно: число столбцов первой матрицы должно совпадать с числом строк второй.

Например:

`(3, 2) @ (2, 4) -> (3, 4)`

## 2. Скалярное произведение векторов

Скалярное произведение двух векторов — сумма произведений соответствующих элементов.

```python
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

print(np.inner(a, b))  # 32
print(np.dot(a, b))    # 32
print(a @ b)           # 32
```

Для одномерных векторов все три варианта дают одинаковый результат.

## 3. Внешнее произведение

`np.outer()` создаёт матрицу из произведений всех элементов первого вектора на элементы второго.

```python
a = np.array([1, 2])
b = np.array([3, 4])

print(np.outer(a, b))

# [[3 4]
#  [6 8]]
```

## 4. Модуль np.linalg

`np.linalg` содержит функции линейной алгебры.

### Ранг матрицы

Ранг — количество линейно независимых строк или столбцов.

```python
a = np.array([[1, 2],
              [2, 4]])

print(np.linalg.matrix_rank(a))  # 1
```

Вторая строка зависит от первой, поэтому ранг равен 1.

### Определитель матрицы

```python
a = np.array([[1, 2],
              [3, 4]])

print(np.linalg.det(a))  # примерно -2.0
```

Если определитель квадратной матрицы равен нулю, обратной матрицы не существует.

Из-за вычислений с плавающей точкой результат может немного отличаться от точного значения.

### Обратная матрица

`np.linalg.inv()` вычисляет обратную матрицу.

```python
a = np.array([[1, 2],
              [3, 4]])

inv_a = np.linalg.inv(a)

print(a @ inv_a)
# Примерно единичная матрица
```

Для обратной матрицы выполняется:

`A @ A^(-1) = I`

где `I` — единичная матрица.

Обратная матрица существует только для невырожденной квадратной матрицы.

### Решение системы линейных уравнений

`np.linalg.solve()` решает систему вида `Ax = b`.

```python
a = np.array([[2, 0],
              [0, 4]])

b = np.array([10, 20])

x = np.linalg.solve(a, b)

print(x)  # [5. 5.]
```

Получаем решение системы:

- 2x₁ = 10
- 4x₂ = 20

Для `solve()` матрица коэффициентов должна быть квадратной и невырожденной.

Обычно для решения системы лучше использовать `solve()`, а не вычислять обратную матрицу вручную.

## 5. Краткая таблица

| Операция | Функция |
|---|---|
| Поэлементное умножение | `a * b` |
| Матричное произведение | `a @ b`, `np.matmul(a, b)` |
| Скалярное произведение | `np.inner(a, b)` |
| Внешнее произведение | `np.outer(a, b)` |
| Ранг матрицы | `np.linalg.matrix_rank(a)` |
| Определитель | `np.linalg.det(a)` |
| Обратная матрица | `np.linalg.inv(a)` |
| Решение системы Ax = b | `np.linalg.solve(a, b)` |

## Что запомнить

- `*` — поэлементное умножение, `@` — матричное.
- При матричном умножении внутренние размерности должны совпадать.
- `inner()` для одномерных векторов вычисляет скалярное произведение.
- `outer()` создаёт матрицу произведений элементов двух векторов.
- `matrix_rank()` определяет ранг матрицы.
- `det()` вычисляет определитель.
- `inv()` находит обратную матрицу.
- `solve()` решает систему линейных уравнений.

Главное — понимать смысл операций, а названия функций запомнятся с практикой.
