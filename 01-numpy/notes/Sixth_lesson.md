# NumPy: объединение и разделение массивов

## Объединение массивов

Общее правило: размеры по всем осям, **кроме той, вдоль которой склеиваем**, должны совпадать. Результат всегда новый массив (копия).

### hstack и vstack

```python
import numpy as np

a = np.array([[1, 2], [3, 4]])
b = np.array([[5, 6], [7, 8]])

print(np.hstack([a, b]))     # по горизонтали (добавляет столбцы)
# [[1 2 5 6]
#  [3 4 7 8]]

print(np.vstack([a, b]))     # по вертикали (добавляет строки)
# [[1 2]
#  [3 4]
#  [5 6]
#  [7 8]]
```

- `hstack` требует одинаковое число **строк**;
- `vstack` требует одинаковое число **столбцов**.

Если размеры не подходят, будет `ValueError`:

```python
np.vstack([a, np.array([[1, 2, 3]])])   # ValueError: в a два столбца, а здесь три
```

### Одномерные массивы и column_stack

```python
aa = np.array([1, 2, 3, 4])
bb = np.array([5, 6, 7, 8])

print(np.hstack([aa, bb]))         # [1 2 3 4 5 6 7 8]  <- просто склеивает в один
print(np.vstack([aa, bb]))         # [[1 2 3 4]
                                   #  [5 6 7 8]]        <- два массива как строки
print(np.column_stack([aa, bb]))   # [[1 5]
                                   #  [2 6]
                                   #  [3 7]
                                   #  [4 8]]            <- два массива как столбцы
```

`column_stack` превращает одномерные массивы в столбцы. Для двумерных массивов он работает так же, как `hstack`.

> `np.row_stack` это старый псевдоним `vstack`. В NumPy 2.x он считается устаревшим, поэтому лучше писать `vstack`.

### concatenate

`np.concatenate([x, y], axis=...)` это универсальная функция: работает с любым числом измерений, а `hstack` и `vstack` по сути её частные случаи.

```python
np.concatenate([a, b], axis=0)   # то же, что vstack
np.concatenate([a, b], axis=1)   # то же, что hstack
```

Для трёхмерных массивов размер растёт по выбранной оси:

```python
mass_a = np.arange(1, 19).reshape(3, 3, 2)
mass_b = np.arange(19, 37).reshape(3, 3, 2)

print(np.concatenate([mass_a, mass_b], axis=0).shape)   # (6, 3, 2)
print(np.concatenate([mass_a, mass_b], axis=1).shape)   # (3, 6, 2)
print(np.concatenate([mass_a, mass_b], axis=2).shape)   # (3, 3, 4)
```

> Массивы для примера создаём через `reshape`, а не `resize`: `reshape` возвращает массив, а `a.resize(...)` меняет массив на месте и возвращает `None`.

### Объекты r_ и c_

Это короткая запись для склейки. Обрати внимание: используются **квадратные скобки**, а не круглые.

```python
x = np.array([1, 2, 3])
y = np.array([4, 5, 6])

print(np.r_[x, y])      # [1 2 3 4 5 6]   <- как hstack для одномерных
print(np.c_[x, y])      # [[1 4]
                        #  [2 5]
                        #  [3 6]]        <- как column_stack
```

`r_` понимает срезы:

```python
print(np.r_[0:5, 10, 20])    # [ 0  1  2  3  4 10 20]
```

## Разделение массивов

Все функции возвращают **список массивов**.

```python
a = np.array([[1, 2], [3, 4]])

left, right = np.hsplit(a, 2)    # по столбцам
print(left)                      # [[1]
                                 #  [3]]
print(right)                     # [[2]
                                 #  [4]]

top, bottom = np.vsplit(a, 2)    # по строкам
print(top)                       # [[1 2]]
print(bottom)                    # [[3 4]]
```

### array_split

По умолчанию делит по `axis=0`, то есть так же, как `vsplit`. Главное отличие: **умеет делить на неравные части**.

```python
print(np.array_split(a, 2))              # как vsplit(a, 2)

print(np.array_split(np.arange(7), 3))
# [array([0, 1, 2]), array([3, 4]), array([5, 6])]

np.hsplit(np.arange(7), 3)               # ValueError: 7 не делится на 3 поровну
```

Разделение по индексам (где резать):

```python
print(np.hsplit(np.arange(10), [3, 7]))
# [array([0, 1, 2]), array([3, 4, 5, 6]), array([7, 8, 9])]
```

## Сводная таблица

| Функция | Что делает | Условие |
|---|---|---|
| `hstack` | склеивает по горизонтали | одинаковое число строк |
| `vstack` | склеивает по вертикали | одинаковое число столбцов |
| `column_stack` | одномерные массивы делает столбцами | одинаковая длина |
| `concatenate` | склеивает вдоль `axis` | совпадают все оси, кроме `axis` |
| `r_` / `c_` | короткая запись склейки | квадратные скобки |
| `hsplit` / `vsplit` | делит по столбцам / по строкам | делится поровну |
| `array_split` | делит на части | допускает неравные части |

## Что запомнить

- `hstack`, `vstack`, `column_stack` частные случаи `concatenate`
- при склейке размеры по остальным осям должны совпадать, иначе `ValueError`
- `row_stack` устарел, пиши `vstack`
- `r_` и `c_` используют квадратные скобки
- `hsplit` и `vsplit` делят только поровну, `array_split` может и неравно
- `a.resize()` возвращает `None`, для нужной формы бери `reshape`
