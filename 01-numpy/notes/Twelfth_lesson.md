# NumPy — урок 12. Множества и операции над ними

В этом уроке разобрал, как получать уникальные элементы массива и выполнять операции над множествами.

## 1. np.unique()

Функция `np.unique()` возвращает уникальные элементы массива.

```python
import numpy as np

a = np.array([3, 1, 2, 3, 2, 1, 4])

print(np.unique(a))
# [1 2 3 4]
```

По умолчанию уникальные элементы сортируются.

### return_counts=True

Показывает количество вхождений каждого уникального элемента.

```python
values, counts = np.unique(a, return_counts=True)

print(values)  # [1 2 3 4]
print(counts)  # [2 2 2 1]
```

### return_index=True

Возвращает индексы первых появлений уникальных элементов в исходном массиве.

```python
values, indices = np.unique(a, return_index=True)

print(values)   # [1 2 3 4]
print(indices)  # [1 2 0 6]
```

### return_inverse=True

Возвращает индексы, с помощью которых можно восстановить исходный массив.

```python
a = np.array([5, 2, 5, 3])

values, inverse = np.unique(a, return_inverse=True)

print(values)   # [2 3 5]
print(inverse)  # [2 0 2 1]

print(values[inverse])  # [5 2 5 3]
```

Как это работает:

- В `values` лежат уникальные элементы: `[2, 3, 5]`.
- Их индексы: `2 -> 0`, `3 -> 1`, `5 -> 2`.
- `inverse` показывает индекс каждого исходного элемента в `values`.

Важно: `return_index` и `return_inverse` — разные вещи!

## 2. Параметр axis

Для двумерных массивов можно искать уникальные строки или столбцы.

```python
a = np.array([
    [1, 2],
    [1, 2],
    [3, 4]
])

print(np.unique(a, axis=0))
# [[1 2]
#  [3 4]]
```

- `axis=0` — уникальные строки.
- `axis=1` — уникальные столбцы.
- Без `axis` массив рассматривается как набор отдельных элементов.

## 3. Операции над множествами

Создадим два массива:

```python
a = np.array([1, 2, 3, 4])
b = np.array([3, 4, 5, 6])
```

### Пересечение — intersect1d()

Элементы, которые есть в обоих массивах.

```python
print(np.intersect1d(a, b))
# [3 4]
```

### Объединение — union1d()

Все уникальные элементы из обоих массивов.

```python
print(np.union1d(a, b))
# [1 2 3 4 5 6]
```

### Разность — setdiff1d()

Элементы первого массива, которых нет во втором.

```python
print(np.setdiff1d(a, b))
# [1 2]

print(np.setdiff1d(b, a))
# [5 6]
```

Порядок аргументов имеет значение!

### Симметрическая разность — setxor1d()

Элементы, которые есть только в одном из массивов.

```python
print(np.setxor1d(a, b))
# [1 2 5 6]
```

Общие элементы `3` и `4` исключаются.

## 4. Проверка вхождения — np.isin()

`np.isin()` проверяет, содержится ли каждый элемент первого массива во втором.

```python
a = np.array([1, 2, 3, 4])
b = np.array([2, 4, 6])

print(np.isin(a, b))
# [False  True False  True]
```

Можно использовать результат для фильтрации:

```python
print(a[np.isin(a, b)])
# [2 4]
```

Если нужны элементы, которых НЕТ во втором массиве:

```python
print(a[~np.isin(a, b)])
# [1 3]
```

`~` инвертирует булеву маску.

Раньше для таких проверок использовали `np.in1d()`, но в современном NumPy лучше использовать `np.isin()`.

## 5. Краткая таблица

| Функция | Что делает |
|---|---|
| `np.unique(a)` | Уникальные элементы |
| `return_counts=True` | Количество вхождений |
| `return_index=True` | Индексы первых появлений |
| `return_inverse=True` | Индексы для восстановления массива |
| `np.unique(a, axis=0)` | Уникальные строки |
| `np.unique(a, axis=1)` | Уникальные столбцы |
| `np.intersect1d(a, b)` | Пересечение |
| `np.union1d(a, b)` | Объединение |
| `np.setdiff1d(a, b)` | Разность |
| `np.setxor1d(a, b)` | Симметрическая разность |
| `np.isin(a, b)` | Проверка вхождения элементов |

## Что запомнить

- `unique()` убирает повторяющиеся элементы.
- `return_counts` показывает, сколько раз встречается каждый элемент.
- `return_index` возвращает индексы первых появлений.
- `return_inverse` позволяет восстановить исходный массив через `values[inverse]`.
- `axis=0` работает со строками, `axis=1` — со столбцами.
- `intersect1d` — общие элементы.
- `union1d` — все уникальные элементы.
- `setdiff1d` — элементы первого массива без элементов второго.
- `setxor1d` — элементы, которые есть только в одном массиве.
- `isin()` удобно использовать вместе с булевой индексацией.
