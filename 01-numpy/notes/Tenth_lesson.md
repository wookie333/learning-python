# NumPy: базовые математические функции

Функции делятся на несколько семейств. Запоминать нужно семейство и одну-две главные функции, остальное находится в документации.

## 1. Агрегации: sum, mean, min, max

Работают и как методы (`a.sum()`), и как функции (`np.sum(a)`), результат одинаковый.

```python
import numpy as np

a = np.array([1, 2, 3, 10, 20, 30])

print(a.sum())      # 66
print(a.min())      # 1
print(a.mean())     # 11.0
```

### Параметр axis

Для многомерных массивов можно считать по оси:

```python
m = np.array([[1, 2, 3],
              [4, 5, 6]])

print(m.sum(axis=0))     # [5 7 9]    <- по столбцам (схлопываем строки)
print(m.sum(axis=1))     # [ 6 15]    <- по строкам (схлопываем столбцы)
print(m.mean(axis=0))    # [2.5 3.5 4.5]
```

`axis` это ось, по которой выполняется агрегация. При `keepdims=False` (по умолчанию) она **исчезает**, а при `keepdims=True` остаётся с длиной 1: `m.sum(axis=1, keepdims=True).shape` будет `(2, 1)`. Для одномерного массива `a.sum(axis=0)` равно просто `a.sum()`.

## 2. Экстремумы и их позиции

```python
new_a = np.array([-1, 1, 5, -44, 32, 2])

print(np.amax(new_a))      # 32    <- значение максимума
print(np.amin(new_a))      # -44   <- значение минимума
print(np.argmax(new_a))    # 4     <- ИНДЕКС максимума (32 стоит на позиции 4)
print(np.argmin(new_a))    # 3     <- ИНДЕКС минимума
```

- `np.amax` и `np.amin` то же, что `np.max` и `np.min`;
- `argmax` и `argmin` возвращают **индекс**, а не значение;
- для двумерного массива без `axis` индекс считается по «развёрнутому» массиву, с `axis` по строкам или столбцам.

## 3. Поэлементные функции: abs, round, log

Применяются к каждому элементу и возвращают массив такой же формы.

```python
print(np.abs(new_a))         # [ 1  1  5 44 32  2]
```

### Округление

```python
print(np.round(0.7))         # 1.0
print(np.round(0.5))         # 0.0   <- не 1.0!
print(np.round(1.5))         # 2.0
print(np.round(2.5))         # 2.0
print(np.round(3.14159, 2))  # 3.14  <- можно указать число знаков
```

При значении ровно `.5` NumPy округляет к **ближайшему чётному** (банковское округление): `0.5` → `0`, `1.5` → `2`, `2.5` → `2`. `np.around` это псевдоним `np.round`.

### Логарифмы

```python
print(np.log(np.e))      # 1.0   <- натуральный логарифм (основание e)
print(np.log2(8))        # 3.0
print(np.log10(1000))    # 3.0
```

`np.log(0)` даёт `-inf`, `np.log` от отрицательного числа даёт `nan` (оба случая с предупреждением).

## 4. Тригонометрия

Углы задаются в **радианах**.

```python
res_a = np.linspace(0, np.pi, 5)

print(np.round(np.sin(res_a), 3))     # [0.    0.707 1.    0.707 0.   ]
print(np.cos(np.pi))                  # -1.0
```

Обратные функции:

```python
print(np.arcsin(1))      # 1.5707963267948966   (π/2)
print(np.arccos(1))      # 0.0
print(np.arctan(1))      # 0.7853981633974483   (π/4)
```

Заметки:

- из градусов в радианы: `np.deg2rad(180)` даёт π;
- `np.sin(np.pi)` равно не ровно `0`, а примерно `1.22e-16`: это обычная погрешность чисел с плавающей точкой, поэтому результаты часто округляют через `np.round`.

## 5. Псевдослучайные числа

```python
np.random.rand()                          # одно число из [0, 1)
np.random.rand(2, 3)                      # массив 2x3 из [0, 1)
np.random.randint(10)                     # целое из 0..9
np.random.randint(1, 10, size=(2, 5))     # целые 1..9, массив 2x5 (верхняя граница не включается)
np.random.randn(2, 3)                     # нормальное распределение N(0, 1), массив 2x3
```

| Функция | Распределение |
|---|---|
| `rand` | равномерное на [0, 1) |
| `randint` | случайные целые, верхняя граница **не** входит |
| `randn` | нормальное, среднее 0, стандартное отклонение 1 |

### seed

`np.random.seed(13)` фиксирует состояние генератора: после него числа будут одинаковыми при каждом запуске. Это нужно для воспроизводимости экспериментов.

```python
np.random.seed(0)
print(np.random.rand())      # 0.5488135039273248  <- при каждом запуске одно и то же
```

> `np.random.seed(...)` возвращает `None`, поэтому печатать его результат (`print(np.random.seed(13))`) бессмысленно.

### Современный способ

Старые функции `np.random.*` работают и встречаются в курсах и чужом коде. В новом коде рекомендуют объект `Generator`:

```python
rng = np.random.default_rng(13)

rng.random((2, 3))                   # аналог rand
rng.integers(1, 10, size=(2, 5))     # аналог randint
rng.standard_normal((2, 3))          # аналог randn
```

## 6. Перемешивание: shuffle и permutation

```python
sh_a = np.arange(10)

np.random.shuffle(sh_a)              # перемешивает САМ массив, возвращает None
print(sh_a)                          # уже перемешанный

b = np.random.permutation(sh_a)      # возвращает НОВЫЙ перемешанный массив
print(sh_a)                          # sh_a не изменился
```

| Функция | На месте? | Что возвращает |
|---|---|---|
| `np.random.shuffle(a)` | да | `None` |
| `np.random.permutation(a)` | нет | новый массив |

`np.random.permutation(10)` перемешивает `np.arange(10)`.

## 7. Статистика

```python
x = np.array([1, 4, 3, 7, 10, 8, 14, 21, 20, 23])
y = np.array([4, 1, 6, 9, 13, 11, 16, 19, 15, 22])

print(np.median(x))     # 9.0                  <- медиана
print(np.var(x))        # 57.29                <- дисперсия
print(np.std(x))        # 7.569015788066504    <- стандартное отклонение
```

### ddof: деление на n или на n-1

По умолчанию `np.var` и `np.std` делят на `n` (дисперсия **генеральной** совокупности). Для **выборочной** оценки нужно `ddof=1`:

```python
print(np.var(x, ddof=1))    # 63.65555555555555
print(np.std(x, ddof=1))    # 7.978443178688155
```

### Корреляция и ковариация

Каждая **строка** входного массива считается отдельной переменной, поэтому `x` и `y` сначала складываем через `vstack`:

```python
XY = np.vstack([x, y])

print(np.corrcoef(XY))
# [[1.         0.93158099]
#  [0.93158099 1.        ]]

print(np.cov(XY))
# [[63.65555556 49.82222222]
#  [49.82222222 44.93333333]]
```

- `corrcoef` вычисляет коэффициенты корреляции Пирсона. Для действительных данных определённый коэффициент лежит от -1 до 1. Здесь 0.93: сильная положительная линейная связь;
- у постоянного признака дисперсия равна нулю, поэтому корреляция с ним не определена: `np.corrcoef` возвращает для неё `nan` и может выдать предупреждение о делении на ноль;
- на диагонали `corrcoef` стоят единицы, если корреляция определена; для постоянного признака там тоже будет `nan`;
- `cov` это матрица ковариаций, на диагонали стоят дисперсии. Обрати внимание: `np.cov` по умолчанию делит на `n-1`, поэтому `63.65...` совпадает с `np.var(x, ddof=1)`, а не с `np.var(x)`.

### correlate

`np.correlate(a, v)` это **взаимная корреляция** (сумма произведений при сдвиге одной последовательности относительно другой), а не коэффициент Пирсона. Для коэффициента Пирсона используется `corrcoef`.

```python
print(np.correlate([1, 2, 3], [0, 1, 0.5]))    # [3.5]  = 1*0 + 2*1 + 3*0.5
```

## Сводная таблица

| Семейство | Функции | Заметка |
|---|---|---|
| Агрегации | `sum`, `mean`, `min`, `max` | есть параметр `axis` |
| Экстремумы | `amax`, `amin`, `argmax`, `argmin` | `arg...` возвращают индекс |
| Поэлементные | `abs`, `round` / `around`, `log`, `log2`, `log10` | `round(0.5)` равно 0 |
| Тригонометрия | `sin`, `cos`, `tan`, `arcsin`, `arccos`, `arctan` | радианы |
| Случайные числа | `rand`, `randint`, `randn`, `seed` | `seed` для воспроизводимости |
| Перемешивание | `shuffle`, `permutation` | `shuffle` на месте, `permutation` копия |
| Статистика | `median`, `var`, `std`, `corrcoef`, `cov`, `correlate` | `ddof=1` для выборки |

## Что запомнить

- при агрегации ось `axis` исчезает, если `keepdims=False`; с `keepdims=True` остаётся длиной 1. Для матрицы `axis=0` даёт результат по столбцам, `axis=1` по строкам
- `argmax` и `argmin` возвращают индекс, а не значение
- `np.round(0.5)` равно `0`: округление к чётному
- углы в тригонометрии задаются в радианах
- `randint` не включает верхнюю границу; `rand` равномерное, `randn` нормальное
- `seed` нужен, чтобы эксперименты воспроизводились; `seed` и `shuffle` возвращают `None`
- `np.var` и `np.std` делят на `n`, а `np.cov` на `n-1`, разница убирается через `ddof`
- `corrcoef` это коэффициент Пирсона, `correlate` совсем другое
