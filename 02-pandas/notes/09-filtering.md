# Pandas — урок 9. Фильтрация данных

## 1. Что такое фильтрация

Фильтрация позволяет выбрать из DataFrame только те строки,
которые удовлетворяют определённому условию.

```python
import pandas as pd

df = pd.DataFrame({
    'age': [53, 37, 11, 18, 7],
    'name': ['Сергей', 'Маша', 'Ксюша', 'Аристарх', 'Соня'],
    'has car': [True, True, False, True, False]
})
```

Например, выберем людей старше 18 лет:

```python
print(df[df['age'] > 18])
```

Выражение df['age'] > 18 создаёт булеву маску:
True — строка подходит.
False — строка не подходит.

Затем df[...] оставляет строки, для которых маска равна True.

## 2. Логические операторы

Основные операторы:

- & — И (AND)
- | — ИЛИ (OR)
- ~ — НЕ (NOT)

### Оператор &

Оба условия должны выполняться:

```python
print(df[(df['age'] > 18) & (df['has car'])])
```

Получим людей старше 18 лет, у которых есть машина.

### Оператор |

Достаточно выполнения хотя бы одного условия:

```python
print(df[(df['age'] == 18) | (~df['has car'])])
```

Получим людей, которым ровно 18 лет,
ИЛИ людей без машины.

### Оператор ~

Меняет True на False, а False на True:

```python
print(df[~df['has car']])
```

Выведет людей без машины.

Важно: при комбинировании условий через & и |
каждое сравнение лучше заключать в круглые скобки.

## 3. Метод isin()

isin() проверяет, входит ли значение в набор.

Пример:

```python
print(df['age'].isin([53, 18, 7]))
```

Результат — булева маска.

Если нужно получить строки:

```python
print(df[df['age'].isin([53, 18, 7])])
```

Это выберет людей с возрастом 53, 18 или 7.

Важно различать:

```python
df.isin([53, 'Ксюша'])
```

Проверяет каждую ячейку всей таблицы.

```python
df['age'].isin([53, 18, 7])
```

Проверяет только столбец age.

```python
df[df['age'].isin([53, 18, 7])]
```

Выбирает строки, в которых возраст подходит.

isin() особенно удобен, если нужно проверить
сразу несколько допустимых значений.

## 4. Метод query()

query() позволяет записывать условия фильтрации строкой.

```python
print(df.query('age > 18'))
```

Через query() можно объединять условия:

```python
print(df.query('age > 18 and `has car`'))
```

Здесь:
- and — И
- or — ИЛИ
- not — НЕ

### Названия столбцов с пробелами

Если название содержит пробел, используем обратные кавычки:

```python
print(df.query('not `has car` and age < 10'))
```

Условие означает:
нет машины И возраст меньше 10 лет.

Получим только Соню.

## 5. Переменные Python внутри query()

Чтобы обратиться к переменной Python внутри query(),
используется символ @.

```python
N = 5

print(df.query('not `has car` and age < 3*@N'))
```

Здесь @N — значение переменной N, то есть 5.

Условие эквивалентно:

```python
print(df.query('not `has car` and age < 15'))
```

Подойдут Ксюша и Соня.

Без @ выражение N внутри query() воспринималось бы
как имя из области данных запроса, а не внешняя
переменная Python.

## 6. Приоритеты логических операций

Обычно AND выполняется раньше OR.

Поэтому:

```python
df.query(
    '(age == 18) or (`has car` and age > 30)'
)
```

означает:
возраст 18 ИЛИ (есть машина И возраст больше 30).

Если хотим сначала объединить альтернативы,
нужно поставить дополнительные скобки.

Например, студенты должны:
- жить в Москве ИЛИ Казани;
- иметь оценку не меньше 80;
- быть младше 22 лет.

Правильная фильтрация:

```python
df.query(
    '((city == "Moscow") or (city == "Kazan")) '
    'and (score >= 80) and (age < 22)'
)
```

Аналог через isin():

```python
df[
    (df['city'].isin(['Moscow', 'Kazan'])) &
    (df['score'] >= 80) &
    (df['age'] < 22)
]
```

Оба способа выбирают одинаковые строки.

## 7. Что использовать в ML

Обычные булевы маски и query() решают похожие задачи.

Булевы маски:
- удобны при работе со Series;
- легко сочетаются с другими операциями Pandas;
- позволяют изменять значения через loc.

query():
- часто делает сложные фильтры более читаемыми;
- поддерживает переменные Python через @.

Для ML особенно важно понимать сами условия,
а не только запоминать синтаксис.

## Главное из урока

- df[условие] — фильтрация строк.
- & — оба условия должны выполняться.
- | — достаточно одного условия.
- ~ — логическое отрицание.
- isin() — проверка принадлежности набору.
- query() — фильтрация с помощью строки.
- @ — обращение к переменной Python внутри query().
- Скобки помогают избежать ошибок с приоритетами.
