# Pandas — урок 12. Методы at, iat, loc, iloc

## 1. Зачем нужны эти методы?

Pandas позволяет обращаться к отдельным ячейкам,
строкам и столбцам DataFrame.

Четыре основных метода:

| Метод | Как обращается | Назначение |
|-------|----------------|------------|
| at | По меткам | Одна ячейка |
| iat | По позициям | Одна ячейка |
| loc | По меткам | Выбор строк и столбцов |
| iloc | По позициям | Выбор строк и столбцов |

Буква i означает integer position — числовую позицию.

## 2. Исходный DataFrame

```python
import pandas as pd

df = pd.DataFrame({
    'name': ['Сергей', 'Маша', 'Ксюша', 'Аристарх', 'Соня'],
    'age': [53, 37, 11, 18, 7],
    'has car': [True, True, False, True, False]
}, index=['row_0', 'row_1', 'row_2', 'row_3', 'row_4'])
```

Столбцы имеют позиции:

- 0 — name
- 1 — age
- 2 — has car

## 3. Метод iat

iat обращается к одной ячейке по числовым позициям.

```python
print(df.iat[2, 1])
```

Результат: 11.

Позиция строки — 2 (Ксюша).
Позиция столбца — 1 (age).

Изменение значения:

```python
df.iat[4, 1] = 10
```

Теперь возраст Сони равен 10.

Важно: iat использует позиции, а не метки.

## 4. Метод at

at обращается к одной ячейке по меткам.

```python
print(df.at['row_3', 'name'])
```

Результат: Аристарх.

Изменение значения:

```python
df.at['row_2', 'age'] = 15
```

Теперь возраст Ксюши равен 15.

at также работает с Series:

```python
print(df['age'].at['row_2'])
```

## 5. Метод iloc

iloc позволяет выбирать строки и столбцы по позициям.

Общий синтаксис:

```python
df.iloc[строки, столбцы]
```

### Одна ячейка

```python
print(df.iloc[1, 1])
```

Результат: 37.

### Срез строк

```python
print(df.iloc[1:4, 0:2])
```

Выбираются:
- строки с позициями 1, 2 и 3;
- столбцы с позициями 0 и 1.

Правая граница среза НЕ включается.

### Series и DataFrame

```python
df.iloc[1:3, 0]
```

Результат — Series.

```python
df.iloc[1:3, [0]]
```

Результат — DataFrame.

Если столбец указан числом — Series.
Если список содержит один столбец — DataFrame.

### Булевые маски с iloc

```python
mask = df['has car'].to_list()

print(mask)
```

Результат:

```text
[True, True, False, True, False]
```

Метод to_list() преобразует Series
в обычный список Python.

Можно использовать его в iloc:

```python
print(df.iloc[
    df['has car'].to_list(),
    [True, False, True]
])
```

Первая маска выбирает строки:
- Сергей
- Маша
- Аристарх

Вторая маска выбирает столбцы:
- name
- has car

Столбец age не выбирается.

Важно: iloc работает с булевыми списками
или массивами, но не принимает напрямую
обычный индексированный булевый Series
в качестве позиционной маски.

При фильтрации по значениям столбцов
обычно удобнее использовать loc.

### Изменение данных

```python
df.iloc[1:3, 1] = 99
```

Изменяется age у Маши и Ксюши.

## 6. Метод loc

loc использует метки строк и названия столбцов.

```python
print(df.loc['row_2', 'name'])
```

Результат: Ксюша.

### Выбор нескольких строк

```python
print(df.loc[['row_1', 'row_2']])
```

### Выбор нескольких столбцов

```python
print(df.loc[:, ['age', 'name']])
```

Символ : означает все строки.

### Срез по меткам

```python
print(df.loc['row_0':'row_3', ['age']])
```

В отличие от iloc, при таком срезе
по упорядоченным меткам правая граница
включается в результат.

Будут выбраны row_0, row_1, row_2, row_3.

## 7. Фильтрация через loc

Найти людей старше 20 лет, у которых есть машина:

```python
print(df.loc[
    (df['age'] > 20) & (df['has car'] == True),
    ['name', 'age']
])
```

Результат:
- Сергей
- Маша

Общий принцип:

```python
df.loc[условие_для_строк, список_столбцов]
```

Несколько условий объединяются:
- & — И
- | — ИЛИ
- ~ — НЕ

Каждое условие нужно заключать в скобки.

Если столбец уже содержит True/False,
можно использовать его напрямую:

```python
print(df.loc[
    (df['age'] > 20) & df['has car'],
    ['name', 'age']
])
```

## 8. Изменение значений через loc

Одно значение:

```python
df.loc['row_1', 'age'] = 20
```

Несколько одинаковых значений:

```python
df.loc['row_1':'row_2', 'age'] = 1
```

Несколько разных значений:

```python
df.loc['row_0':'row_2', 'age'] = [10, 20, 30]
```

## 9. Присваивание Series

```python
values = pd.Series(
    [22, 33, 44],
    index=['row_0', 'row_1', 'row_2']
)

df.loc['row_0':'row_2', 'age'] = values
```

Pandas сопоставляет значения Series
с метками строк DataFrame.

Важно учитывать совместимость типов данных.

Например, запись строк в числовой столбец
может привести к ошибке несовместимых типов.

## 10. Присваивание DataFrame

Можно менять несколько столбцов сразу:

```python
new_values = pd.DataFrame({
    'name': ['Сергей', 'Маша', 'Ксюша'],
    'age': [22, 33, 44]
}, index=['row_0', 'row_1', 'row_2'])

df.loc[
    'row_0':'row_2',
    ['age', 'name']
] = new_values
```

При таком присваивании через loc
Pandas учитывает совпадение меток
строк и названий столбцов.

## 11. Частые ошибки

### Ошибка 1. Путаница позиций и меток

```python
df.iat[4, 0] = 10
```

Это изменение столбца name, а не age!

Правильное обращение к возрасту Сони:

```python
df.iat[4, 1] = 10
```

### Ошибка 2. Неправильное объединение условий

Условия должны быть объединены
внутри первой части loc:

```python
df.loc[
    (df['age'] > 20) & (df['has car'] == True),
    ['name', 'age']
]
```

### Ошибка 3. Путаница Series и DataFrame

```python
df.loc[:, 'name']     # Series
df.loc[:, ['name']]   # DataFrame
```

## Главное из урока

- at — одна ячейка по меткам.
- iat — одна ячейка по позициям.
- loc — выбор по меткам, условиям и названиям.
- iloc — выбор по числовым позициям.
- iloc обычно не включает правую границу среза.
- loc включает конечную метку при обычном срезе.
- loc удобен для фильтрации по условиям.
- Series при присваивании через loc
  может выравниваться по индексам.
- При изменении данных нужно учитывать их типы.

Для ML наиболее важны loc и iloc:
они постоянно используются при подготовке,
фильтрации и исследовании данных.
