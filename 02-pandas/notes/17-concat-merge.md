# Pandas — урок 17. Объединение данных: concat() и merge()

## 1. Зачем объединять DataFrame?

В реальных задачах информация часто хранится
в разных таблицах: пользователи, заказы, товары.

Основные инструменты:

- pd.concat() — соединение таблиц по строкам или столбцам.
- merge() — объединение таблиц по общим ключам.

## 2. Метод pd.concat()

```python
import pandas as pd

df1 = pd.DataFrame({
    'name': ['Ilya', 'Max'],
    'score': [90, 80]
})

df2 = pd.DataFrame({
    'name': ['Alex', 'Dima'],
    'score': [75, 95]
})
```

Добавить строки второй таблицы:

```python
result = pd.concat([df1, df2], ignore_index=True)
```

По умолчанию axis=0 — соединение по строкам.

ignore_index=True создаёт новый индекс:
0, 1, 2, 3.

Без него исходные индексы сохраняются.

Соединение по столбцам:

```python
pd.concat([df1, df2], axis=1)
```

При axis=1 строки сопоставляются по индексам.
Если индексы не совпадают, возможны NaN.

## 3. Метод merge()

merge() объединяет таблицы по общему ключу.

```python
users = pd.DataFrame({
    'user_id': [1, 2, 3],
    'name': ['Ilya', 'Max', 'Alex']
})

cities = pd.DataFrame({
    'user_id': [1, 3, 4],
    'city': ['Moscow', 'Kazan', 'Sochi']
})
```

Объединение:

```python
result = users.merge(cities, on='user_id')
```

on='user_id' — общий столбец для объединения.

По умолчанию используется how='inner'.

## 4. Основные типы объединения

### inner

```python
users.merge(cities, on='user_id', how='inner')
```

Остаются только ключи, присутствующие
в обеих таблицах.

В примере: user_id 1 и 3.

### left

```python
users.merge(cities, on='user_id', how='left')
```

Сохраняются все строки левой таблицы.

У Max значение city будет NaN.

### right

```python
users.merge(cities, on='user_id', how='right')
```

Сохраняются все строки правой таблицы.

Для user_id=4 имя будет NaN.

### outer

```python
users.merge(cities, on='user_id', how='outer')
```

Сохраняются все ключи обеих таблиц.

В примере: 1, 2, 3, 4.

## 5. Параметр indicator=True

```python
result = users.merge(
    cities,
    on='user_id',
    how='outer',
    indicator=True
)
```

Добавляется столбец _merge:

- both — ключ найден в обеих таблицах.
- left_only — ключ только в левой таблице.
- right_only — ключ только в правой таблице.

Полезно для поиска несовпадений.

## 6. Параметр validate

Позволяет проверять уникальность ключей
перед объединением.

```python
users.merge(
    cities,
    on='user_id',
    how='left',
    validate='1:1'
)
```

Варианты:

- '1:1' — ключи уникальны в обеих таблицах.
- '1:m' — ключи уникальны слева.
- 'm:1' — ключи уникальны справа.
- 'm:m' — допускаются повторы с обеих сторон,
  но проверка уникальности не выполняется.

Если условие нарушено, Pandas выдаёт ошибку.

## 7. Важные нюансы

### Дублирование строк

Если один ключ встречается несколько раз
в обеих таблицах, merge() может увеличить
количество строк в результате.

Поэтому полезно проверять уникальность ключей
и количество строк до и после объединения.

### NaN в ключах

В Pandas строки с отсутствующими ключами
могут сопоставляться друг с другом.

Это отличается от обычного SQL JOIN.

### Разные названия ключей

Можно указать:

```python
left.merge(
    right,
    left_on='user_id',
    right_on='customer_id'
)
```

## 8. Применение в ML

Объединение таблиц используется для:

- добавления признаков к основной таблице;
- соединения данных пользователей и заказов;
- объединения нескольких источников данных;
- подготовки датасета для обучения модели.

Нужно следить за:
- количеством строк после merge();
- дублирующимися ключами;
- пропущенными значениями;
- утечкой данных из будущего или тестовой выборки.

## Главное из урока

- concat() — соединение таблиц.
- ignore_index=True — новый индекс.
- merge() — объединение по общему ключу.
- inner — только совпадающие ключи.
- left — сохраняем строки слева.
- right — сохраняем строки справа.
- outer — сохраняем ключи с обеих сторон.
- indicator=True — происхождение строк.
- validate — проверка уникальности ключей.

Для ML особенно важно уверенно использовать
merge() и понимать последствия объединения.
