# Pandas — урок 16. Группировка данных: groupby()

## 1. Что такое groupby()?

groupby() группирует строки по одинаковым
значениям одного или нескольких столбцов.

После группировки можно вычислять статистики
отдельно для каждой группы.

Общий принцип:

1. Разделить данные на группы.
2. Применить операцию к каждой группе.
3. Получить объединённый результат.

## 2. Исходный DataFrame

```python
import pandas as pd

df = pd.DataFrame({
    'city': ['Moscow', 'Kazan', 'Moscow', 'Kazan', 'Moscow', 'Sochi'],
    'category': ['Books', 'Books', 'Tech', 'Tech', 'Books', 'Books'],
    'revenue': [1000, 500, 2000, 900, 3000, 700],
    'items': [2, 1, 4, 2, 3, 1]
})
```

## 3. Группировка по одному столбцу

Общая выручка по каждому городу:

```python
print(df.groupby('city')['revenue'].sum())
```

Результат:

```text
city
Kazan     1400
Moscow    6000
Sochi      700
```

Разбор:

- groupby('city') — группировка по городам.
- ['revenue'] — выбор столбца с выручкой.
- sum() — сумма выручки внутри каждой группы.

Также можно использовать:

```python
df.groupby('city')['revenue'].mean()
df.groupby('city')['revenue'].min()
df.groupby('city')['revenue'].max()
```

## 4. groupby() + agg()

Из прошлого урока мы знаем, что agg()
позволяет вычислять несколько статистик сразу.

```python
print(df.groupby('city')['revenue'].agg(
    ['sum', 'mean', 'max']
))
```

Можно применять разные функции
к разным столбцам:

```python
print(df.groupby('city').agg({
    'revenue': ['sum', 'mean'],
    'items': 'sum'
}))
```

## 5. Группировка по нескольким столбцам

```python
print(df.groupby(
    ['city', 'category']
)['revenue'].sum())
```

Теперь группировка выполняется
по сочетаниям города и категории.

Например:

- Moscow + Books
- Moscow + Tech
- Kazan + Books
- Kazan + Tech

При обычной группировке по двум столбцам
результат может иметь MultiIndex.

## 6. Параметр as_index=False

По умолчанию значения, по которым выполняется
группировка, становятся индексом результата.

```python
df.groupby('city')['revenue'].sum()
```

Если нужен обычный DataFrame, где city
остаётся отдельным столбцом:

```python
print(df.groupby(
    'city', as_index=False
)['revenue'].sum())
```

Это удобно для дальнейшей обработки данных.

## 7. Именованные агрегации

Можно самостоятельно задавать названия
результирующих столбцов.

```python
result = df.groupby(
    'city', as_index=False
).agg(
    total_revenue=('revenue', 'sum'),
    average_revenue=('revenue', 'mean'),
    sales_count=('revenue', 'size')
)

print(result)
```

Разбор:

- total_revenue — общая выручка.
- average_revenue — средняя выручка.
- sales_count — количество строк в группе.

Общий синтаксис:

новое_название=('исходный_столбец', 'операция')

## 8. Разница между size() и count()

size() — считает все строки внутри группы.

count() — считает непустые значения
выбранного столбца.

Например:

```python
df.groupby('city').size()
df.groupby('city')['revenue'].count()
```

Если в revenue есть NaN, результаты
двух операций могут различаться.

## 9. Пропущенные значения в группах

По умолчанию groupby() не создаёт отдельную
группу для пропущенного ключа группировки.

Если нужно учитывать такие группы:

```python
df.groupby('city', dropna=False)['revenue'].sum()
```

## 10. Зачем это нужно в Data Science и ML?

groupby() применяется для:

- анализа продаж по категориям;
- расчёта среднего чека по клиентам;
- подсчёта количества заказов;
- анализа статистик по городам и периодам;
- создания агрегированных признаков.

При создании признаков для ML нужно
избегать утечки информации из тестовых
данных или будущих наблюдений.

## Главное из урока

- groupby() — разделение строк на группы.
- groupby('city') — группировка по одному признаку.
- groupby(['city', 'category']) — по нескольким.
- agg() — вычисление нескольких статистик.
- as_index=False — оставить ключи обычными столбцами.
- Именованные агрегации — понятные имена результатов.
- size() — количество строк в группе.
- count() — количество непустых значений.

groupby() + agg() — одна из самых полезных
комбинаций Pandas для анализа данных.
