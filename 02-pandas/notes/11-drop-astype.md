# Pandas — урок 11. Удаление строк, столбцов и astype()

## 1. Метод drop()

Метод drop() позволяет удалять строки и столбцы
DataFrame по их меткам.

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    'col_1': [5, 6, np.nan, 3, 7],
    'col_2': [27, 6, 7, 40, 70],
    'col_3': [1, 45, 6, 62, 7]
}, index=['row_1', 'row_2', 'row_3', 'row_4', 'row_5'])
```

### Удаление строк

```python
print(df.drop('row_2'))
```

Удалится строка с индексом row_2.

Несколько строк:

```python
print(df.drop(['row_1', 'row_3']))
```

Можно явно указать аргумент index:

```python
print(df.drop(index='row_3'))
```

### Удаление столбцов

```python
print(df.drop(['col_2', 'col_3'], axis=1))
```

axis=1 означает, что удаляем столбцы.

Более читаемый вариант:

```python
print(df.drop(columns=['col_2', 'col_3']))
```

### Одновременное удаление строк и столбцов

```python
print(df.drop(index='row_3', columns='col_3'))
```

## 2. inplace=True

По умолчанию drop() возвращает новый DataFrame,
не изменяя исходный.

```python
new_df = df.drop(index='row_2')
```

Если нужно изменить исходный DataFrame:

```python
df.drop(index='row_2', inplace=True)
```

Метод с inplace=True возвращает None.

Поэтому:

```python
print(df.drop(index='row_2', inplace=True))
```

выведет None, а не изменённую таблицу.

Правильно:

```python
df.drop(index='row_2', inplace=True)
print(df)
```

## 3. Метод astype()

astype() используется для изменения типов данных.

```python
df = pd.DataFrame({
    'age': [19, 20, 21],
    'score': [85.0, 92.0, 78.0],
    'city': ['Moscow', 'Kazan', 'Moscow']
})
```

Посмотреть текущие типы:

```python
print(df.dtypes)
```

Изменить тип одного столбца:

```python
new_df = df.astype({'score': np.int32})
```

Изменить несколько типов одновременно:

```python
new_df = df.astype({
    'score': np.int32,
    'city': 'category'
})
```

По умолчанию astype() возвращает новый DataFrame.
Чтобы сохранить изменения в исходной переменной:

```python
df = df.astype({'score': np.int32})
```

## 4. Числовые типы и память

Часто встречаются следующие типы:

- int8 — 1 байт на значение.
- int16 — 2 байта.
- int32 — 4 байта.
- int64 — 8 байт.
- float32 — 4 байта.
- float64 — 8 байт.

Но тип нужно выбирать с учётом допустимого
диапазона значений и необходимой точности.

Например, int8 хранит числа от -128 до 127.

Поэтому для значений от 0 до 999 int8 не подходит.
Нужно использовать как минимум int16.

Важно: преобразование float в int может потерять
дробную часть, а пропуски NaN могут мешать
преобразованию в обычные целочисленные типы.

## 5. Тип category

Тип category полезен для столбцов, в которых
часто повторяется небольшое число значений.

Например:

```python
df = pd.DataFrame({
    'city': ['Moscow', 'Kazan', 'Moscow', 'Kazan']
})

df['city'] = df['city'].astype('category')
```

В DataFrame по-прежнему будут отображаться
Moscow и Kazan.

Но Pandas будет хранить уникальные категории
и соответствующие им числовые коды.

Это может уменьшать расход памяти.

Особенно полезно, когда:
- строк очень много;
- уникальных категорий сравнительно мало;
- значения часто повторяются.

Важно: на маленьких таблицах category
может занимать даже больше памяти.

Тип category не означает, что признак уже
подготовлен для любой ML-модели.

## 6. Метод memory_usage()

memory_usage() показывает расход памяти
по столбцам DataFrame.

```python
print(df.memory_usage())
```

Однако обычный вызов не всегда учитывает
память, выделенную для строковых объектов.

Для более подробной оценки:

```python
print(df.memory_usage(deep=True))
```

Сравнение до и после преобразований:

```python
print(df.memory_usage(deep=True))
print(new_df.memory_usage(deep=True))
```

Например, преобразование float64 в int32
уменьшает размер числового столбца с
8 до 4 байт на значение.

А преобразование строк в category
не гарантирует уменьшения памяти:
всё зависит от числа строк и категорий.

## 7. Генерация категорий

В уроке встречался такой код:

```python
category_list = ['a', 'b', 'c', 'd', 'e']

result = [category_list[i % 5] for i in range(8)]
print(result)
```

Результат:

```text
['a', 'b', 'c', 'd', 'e', 'a', 'b', 'c']
```

Оператор % вычисляет остаток от деления.

Остатки от деления на 5:
0, 1, 2, 3, 4, 0, 1, 2 ...

Поэтому буквы повторяются по кругу.

## 8. Работа с датами

В уроке использовался метод date_range():

```python
dates = pd.date_range(
    start='2000-01-01',
    periods=5
)
```

Создаются пять последовательных дат.

По умолчанию шаг равен одному дню.

### strftime()

```python
dates_text = dates.strftime('%m-%d-%Y')
```

Преобразует даты в строки:

```text
01-01-2000
01-02-2000
01-03-2000
01-04-2000
01-05-2000
```

Здесь:
- %m — месяц;
- %d — день;
- %Y — год.

После strftime() значения представлены строками.

### Преобразование обратно в даты

```python
df['date'] = pd.to_datetime(
    df['date'],
    format='%m-%d-%Y'
)
```

В результате столбец будет содержать
значения типа datetime64[ns].

Явное указание формата помогает избежать
неправильной интерпретации дат.

## 9. reset_index(drop=True)

```python
df.reset_index(drop=True, inplace=True)
```

Создаёт стандартный числовой индекс.

drop=True означает, что старый индекс
не будет сохранён как отдельный столбец.

При inplace=True результат вызова — None,
но исходный DataFrame изменяется.

## Главное из урока

- drop() — удаление строк и столбцов по меткам.
- index= — указать удаляемые строки.
- columns= — указать удаляемые столбцы.
- axis=0 — строки; axis=1 — столбцы.
- inplace=True — изменить исходный объект.
- astype() — преобразовать типы данных.
- category — тип для категориальных значений.
- memory_usage() — оценить расход памяти.
- deep=True — учитывать дополнительную память объектов.
- date_range() — создать последовательность дат.
- strftime() — преобразовать даты в строки.
- pd.to_datetime() — преобразовать строки в даты.
