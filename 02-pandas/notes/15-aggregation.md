# Pandas — урок 15. Агрегация данных и agg()

## 1. Что такое агрегация?

Агрегация — получение сводных характеристик
из набора данных.

Основные методы:

| Метод | Назначение |
|-------|------------|
| sum() | Сумма |
| mean() | Среднее |
| min() | Минимум |
| max() | Максимум |
| median() | Медиана |
| count() | Количество значений без пропусков |
| std() | Стандартное отклонение |

## 2. Метод agg()

agg() позволяет применить одну или несколько
агрегирующих функций к данным.

```python
import pandas as pd

df = pd.DataFrame({
    'name': ['Ilya', 'Max', 'Alex', 'Dima'],
    'math': [90, 65, 80, 40],
    'english': [75, 85, 95, 60]
})
```

### Несколько функций сразу

```python
print(df[['math', 'english']].agg(
    ['min', 'mean', 'max']
))
```

Результат:

| | math | english |
|---|---|---|
| min | 40 | 60 |
| mean | 68.75 | 78.75 |
| max | 90 | 95 |

По умолчанию агрегация выполняется
по каждому столбцу (axis=0).

## 3. Словарь внутри agg()

Можно назначить разным столбцам
разные агрегирующие функции:

```python
print(df.agg({
    'math': 'sum',
    'english': 'mean'
}))
```

Результат:

```text
math       275.00
english     78.75
dtype: float64
```

Можно указать и несколько функций
для каждого столбца:

```python
print(df.agg({
    'math': ['min', 'mean', 'max'],
    'english': ['min', 'mean', 'max']
}))
```

## 4. Series.agg() и DataFrame.agg()

Важное различие:

```python
df['math']      # Series
df[['math']]    # DataFrame
```

Если использовать agg() для Series:

```python
print(df['math'].agg(['min', 'mean', 'max']))
```

Результат — Series:

```text
min     40.00
mean    68.75
max     90.00
dtype: float64
```

Если передать словарь с несколькими
функциями в DataFrame.agg():

```python
print(df.agg({
    'math': ['min', 'mean', 'max']
}))
```

Результат — DataFrame с одним столбцом.

## 5. Отличие agg() от apply()

apply() — общий инструмент применения функций.
Он может как преобразовывать данные,
так и вычислять сводные значения.

agg() — метод, предназначенный для агрегации,
особенно нескольких статистик сразу.

Пример:

```python
df['math'].agg('mean')   # Одно среднее значение
df['math'].agg(['min', 'max', 'mean'])
```

Для одной простой операции можно
использовать готовый метод:

```python
df['math'].mean()
```

## 6. Для чего это нужно в ML?

Агрегация используется для:

- Первичного анализа датасета.
- Поиска минимальных и максимальных значений.
- Расчёта средних и медиан.
- Проверки распределений и пропусков.
- Получения сводных статистик по признакам.

В следующем уроке изучим groupby().
Вместе с agg() он позволяет получать
статистики отдельно для разных групп.

## Главное из урока

- agg() — выполнение агрегирующих функций.
- Список функций — несколько статистик сразу.
- Словарь — разные функции для разных столбцов.
- Series.agg() может вернуть Series.
- DataFrame.agg() может вернуть DataFrame.
- По умолчанию DataFrame.agg() работает по столбцам.
- Для простых операций подходят sum(), mean(), max().
