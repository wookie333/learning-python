# Урок 1. Знакомство с Pandas

## Что такое Pandas?

Pandas — библиотека Python для работы с табличными данными.
Используется для анализа, обработки и подготовки данных для ML.

## Основные структуры данных

### Series

Series — одномерная структура данных с индексами.

- Похожа на один столбец таблицы.
- У каждого элемента есть индекс.
- Данные обычно имеют один тип.

### DataFrame

DataFrame — двумерная таблица со строками и столбцами.

- У столбцов есть названия.
- У строк есть индексы.
- Разные столбцы могут иметь разные типы данных.
- Удобен для хранения и анализа датасетов.

## Типы данных

- `int64` — целые числа.
- `float64` — вещественные числа.
- `bool` — логические значения.
- `string` — строки.
- `object` — общий тип для Python-объектов.
- `category` — категориальные данные.
- `datetime64` — даты и время.

## Пропущенные значения

`NaN` — специальное значение, которое часто обозначает
отсутствующие числовые данные.

Также в Pandas используется `pd.NA` для пропусков.

## Отличие Pandas от NumPy

NumPy в основном работает с однородными массивами.

В Pandas DataFrame можно хранить столбцы разных типов,
а также обращаться к данным по названиям столбцов и индексам строк.
