# Pandas — урок 19. Работа с датами

## 1. Зачем нужны даты в Pandas?

В реальных датасетах часто встречаются даты:
заказы, транзакции, посещения, регистрации.

Pandas позволяет:
- преобразовывать строки в даты;
- извлекать год, месяц и день недели;
- фильтровать данные по периодам;
- группировать данные по времени;
- создавать временные признаки для ML.

## 2. pd.to_datetime()

Исходный DataFrame:

```python
import pandas as pd

df = pd.DataFrame({
    'order_id': [101, 102, 103, 104, 105],
    'date': [
        '2026-10-25',
        '2026-10-28',
        '2026-11-01',
        '2026-11-03',
        '2026-11-05'
    ],
    'revenue': [1200, 2500, 800, 3100, 1700]
})
```

Столбец date изначально содержит строки.

Преобразование:

```python
df['date'] = pd.to_datetime(df['date'])
print(df.dtypes)
```

Теперь значения имеют тип даты и времени,
а не обычных строк.

## 3. Извлечение информации через .dt

Атрибут .dt позволяет получать компоненты даты.

```python
df['year'] = df['date'].dt.year
df['month'] = df['date'].dt.month
df['day'] = df['date'].dt.day
df['weekday'] = df['date'].dt.dayofweek
```

dayofweek:
- 0 — понедельник;
- 1 — вторник;
- ...
- 6 — воскресенье.

Также существует написание day_of_week.

Другие полезные возможности:

```python
df['date'].dt.day_name()
df['date'].dt.quarter
df['date'].dt.is_month_end
```

В ML компоненты даты могут использоваться
в качестве дополнительных признаков.

## 4. pd.date_range()

Создаёт последовательность дат.

```python
dates = pd.date_range(
    start='2026-11-01',
    periods=5,
    freq='D'
)
```

Параметры:
- start — начало;
- end — конец;
- periods — количество дат;
- freq — частота.

Примеры частот:
- D — каждый день;
- h — каждый час;
- MS — начало каждого месяца.

## 5. Фильтрация по датам

Выбрать заказы за ноябрь 2026 года:

```python
result = df.loc[
    (df['date'] >= '2026-11-01') &
    (df['date'] < '2026-12-01')
]
```

Такой способ выбирает конкретный период.

Можно фильтровать только по номеру месяца:

```python
df.loc[df['date'].dt.month == 11]
```

Но этот вариант выбирает ноябрь за ВСЕ годы.

Поэтому, если нужен конкретный год и месяц,
лучше использовать границы периода.

## 6. Группировка по времени

Общая и средняя выручка по месяцам:

```python
df['month'] = df['date'].dt.month

result = df.groupby('month').agg(
    total_revenue=('revenue', 'sum'),
    average_revenue=('revenue', 'mean')
)
```

Важно: такая группировка объединит
одинаковые месяцы разных лет.

Если нужны отдельные месяцы каждого года:

```python
result = df.groupby(
    df['date'].dt.to_period('M')
).agg(
    total_revenue=('revenue', 'sum'),
    average_revenue=('revenue', 'mean')
)
```

Результат группируется по периодам
вида 2026-10, 2026-11 и так далее.

## 7. Некорректные даты

В данных могут встретиться неправильные строки.

```python
dates = pd.Series([
    '2026-11-01',
    '2026-11-02',
    'unknown'
])

result = pd.to_datetime(dates, errors='coerce')
```

errors='coerce' превращает некорректные
значения в NaT — пропущенную дату.

Можно явно указать формат:

```python
pd.to_datetime(
    pd.Series(['04.11.2026', '05.11.2026']),
    format='%d.%m.%Y'
)
```

%d — день, %m — месяц, %Y — год.

## 8. Применение в Machine Learning

Работа с датами полезна для:
- создания календарных признаков;
- анализа сезонности;
- изучения поведения пользователей во времени;
- анализа продаж по дням и месяцам;
- прогнозирования временных рядов.

Важно не использовать будущую информацию
при подготовке признаков для прогнозов.

## Главное из урока

- pd.to_datetime() — преобразование в даты.
- .dt — извлечение компонентов даты.
- .dt.month — номер месяца.
- .dt.dayofweek — номер дня недели.
- pd.date_range() — последовательность дат.
- loc — фильтрация по временным диапазонам.
- errors='coerce' — некорректные даты в NaT.
- to_period('M') — группировка по годам и месяцам.
