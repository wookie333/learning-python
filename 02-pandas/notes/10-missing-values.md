# Pandas — урок 10. Пропуски в данных

## 1. Что такое NaN

NaN — специальное значение, обозначающее
отсутствующие данные.

Пример:

```python
import numpy as np
import pandas as pd

df = pd.DataFrame({
    'age': [53, np.nan, 11, 18, 7],
    'name': ['Сергей', 'Маша', 'Ксюша', 'Аристарх', 'Соня'],
    'наличие авто': [True, True, False, np.nan, False],
    'марка авто': [np.nan, np.nan, np.nan, np.nan, np.nan]
})
```

В таблице:
- У Маши неизвестен возраст.
- У Аристарха неизвестно наличие машины.
- Весь столбец «марка авто» состоит из пропусков.

Важно: NaN и False — не одно и то же.

False означает, что значение известно и оно ложно.
NaN означает, что значение отсутствует.

## 2. Метод dropna()

dropna() удаляет строки или столбцы с пропусками.

```python
df.dropna()
```

По умолчанию удаляются строки, в которых
есть хотя бы один пропуск.

В нашем примере результат будет пустым:
столбец «марка авто» содержит NaN в каждой строке.

### axis

```python
df.dropna(axis=0)
```

axis=0 — удаляем строки. Это значение по умолчанию.

```python
df.dropna(axis=1)
```

axis=1 — удаляем столбцы.

### how

```python
df.dropna(how='any')
```

Удаляет строку или столбец, если есть хотя бы один NaN.

```python
df.dropna(how='all', axis=1)
```

Удаляет столбец, только если все его значения пропущены.

В нашем случае удалится только «марка авто».

## 3. Аргумент subset

subset указывает, где именно искать пропуски.

Это не список столбцов, которые нужно удалить!

### Удаление строк

```python
df.dropna(subset=['age'])
```

Проверяем пропуски только в столбце age.

Удалится Маша, потому что у неё age = NaN.

Аристарх останется, хотя у него неизвестно
наличие машины: этот столбец мы не проверяем.

### Проверка нескольких столбцов

```python
df.dropna(subset=['age', 'наличие авто'])
```

Удалятся:
- Маша: нет возраста.
- Аристарх: нет информации о машине.

Останутся Сергей, Ксюша и Соня.

### subset при axis=1

```python
df.dropna(subset=[1], axis=1)
```

Теперь мы удаляем столбцы.

Поэтому subset=[1] указывает не столбец,
а строку с индексом 1.

В строке Маши пропуски находятся в:
- age;
- марка авто.

Эти два столбца удалятся из всей таблицы.

Главное правило:
- axis=0: удаляем строки, subset содержит метки столбцов.
- axis=1: удаляем столбцы, subset содержит метки строк.

## 4. inplace=True

По умолчанию dropna() возвращает новый DataFrame
и не меняет исходную таблицу.

```python
new_df = df.dropna(subset=['age'])
```

Если нужно изменить существующий DataFrame:

```python
df.dropna(subset=['age'], inplace=True)
```

Метод с inplace=True возвращает None.

Поэтому не нужно писать:

```python
print(df.dropna(inplace=True))
```

Если хочешь увидеть изменённую таблицу:

```python
df.dropna(subset=['age'], inplace=True)
print(df)
```

## 5. Метод fillna()

fillna() заполняет пропущенные значения.

### Одно значение для всех пропусков

```python
print(df.fillna(6))
```

Все пропуски будут заменены на 6.

Но такая замена не всегда имеет смысл.

### Разные значения для разных столбцов

```python
print(df.fillna({
    'age': 25,
    'наличие авто': False
}))
```

Пропуски в age заменяются на 25.
Пропуски в «наличие авто» заменяются на False.

Остальные столбцы не изменяются.

### inplace=True

```python
df.fillna({'age': 25}, inplace=True)
```

Изменяет исходный DataFrame и возвращает None.

## 6. isna() и notna()

### isna()

Проверяет, отсутствует ли значение.

```python
print(df.isna())
```

NaN превращается в True.
Обычное значение — в False.

Можно проверить отдельный столбец:

```python
print(df['age'].isna())
```

### notna()

Проверяет, присутствует ли значение.

```python
print(df['age'].notna())
```

True — возраст известен.
False — возраст отсутствует.

## 7. Фильтрация по наличию пропусков

Вывести людей, возраст которых известен:

```python
print(df[df['age'].notna()])
```

То же самое через отрицание:

```python
print(df[~df['age'].isna()])
```

Оба способа эквивалентны.

### Комбинирование условий

Найти людей, у которых:
- известен возраст;
- точно нет машины.

```python
print(df[
    (df['age'].notna()) &
    (df['наличие авто'] == False)
])
```

Результат: Ксюша и Соня.

Важно:

```python
df['наличие авто'].isna()
```

означает, что информация отсутствует.

А:

```python
df['наличие авто'] == False
```

означает, что машина отсутствует.

NaN при сравнении с False не становится True.

## 8. Почему это важно для ML

В реальных датасетах часто есть пропуски.

В зависимости от задачи можно:
- удалить строки с пропусками;
- удалить ненужные пустые столбцы;
- заполнить пропуски подходящими значениями.

Но нельзя бездумно удалять все строки или
подставлять случайное число вместо неизвестного значения.

Для числовых признаков иногда используют медиану.
Для категориальных — отдельную категорию «Неизвестно».

Важно: при обучении модели правила заполнения
нужно определять по обучающей выборке,
чтобы избежать утечки данных из тестовой.

## Главное из урока

- NaN — отсутствующее значение.
- dropna() — удаление строк или столбцов.
- axis=0 — строки.
- axis=1 — столбцы.
- how='any' — удалить при любом пропуске.
- how='all' — удалить, только если все значения пропущены.
- subset — где проверять пропуски.
- fillna() — заполнение пропусков.
- isna() — поиск отсутствующих значений.
- notna() — поиск присутствующих значений.
- inplace=True — изменение исходной таблицы.
- NaN и False — разные значения.
