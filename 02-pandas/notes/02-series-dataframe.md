# Урок 2. Создание Series и DataFrame

## Series

`Series` — одномерная структура данных Pandas с индексами.

Создать Series можно из:
- списка Python;
- словаря;
- массива NumPy;
- другой Series.

Пример:

```python
import pandas as pd

grades = pd.Series(
    [5, 4, 3],
    index=['Ilya', 'Max', 'Alex'],
    name='grades'
)
```

Основные параметры:
- `data` — данные;
- `index` — индексы элементов;
- `dtype` — тип данных;
- `name` — название Series;
- `copy` — управление копированием данных.

## DataFrame

`DataFrame` — двумерная таблица со строками и столбцами.

Чаще всего создаётся из словаря:

```python
df = pd.DataFrame({
    'name': ['Ilya', 'Max', 'Alex'],
    'age': [19, 20, 21],
    'score': [85, 92, 78]
})
```

Основные параметры:
- `data` — исходные данные;
- `index` — индексы строк;
- `columns` — названия и порядок столбцов;
- `dtype` — тип данных;
- `copy` — управление копированием.

Если в `columns` указать несуществующий столбец,
Pandas создаст его с пропущенными значениями.

## Индексация

`loc` — обращение по меткам.

`iloc` — обращение по позициям.

```python
grades.loc['Alex'] = 4
grades.iloc[0] = 5
```

В срезах через `loc` конечная метка включается.

## Копирование данных

`copy=True` — запрашивает копирование данных.

`copy=False` — позволяет не копировать данные,
но не всегда гарантирует общую память.

Например, Series из NumPy-массива может использовать
ту же память, что и исходный массив.

## Выравнивание индексов

Pandas сопоставляет значения Series по индексам,
а не по их позициям.

```python
a = pd.Series([10, 20, 30], index=['A', 'B', 'C'])
b = pd.Series([100, 200, 300], index=['B', 'C', 'D'])

df = pd.DataFrame({'a': a, 'b': b})
```

Индексы итоговой таблицы: A, B, C, D.

Если для какого-то индекса значения нет,
появится пропуск (`NaN` или другое представление
пропущенного значения в зависимости от dtype).

## Что запомнил

- Series — одномерная структура.
- DataFrame — двумерная таблица.
- DataFrame можно создавать из словаря и NumPy-массива.
- `loc` работает по меткам, `iloc` — по позициям.
- Pandas автоматически выравнивает данные по индексам.
- Копирование зависит от типа данных и способа создания объекта.
